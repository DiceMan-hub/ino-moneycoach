# Research-Efficiency（リサーチ効率化）

Cursor・Claude Code などを活用した**リサーチ（情報収集）の効率化**に関連する資料をまとめるフォルダ。

## 目的

- 毎日の情報収集時間を削減する
- AIに「自分専用のニュース／トレンド一覧」を作らせ、選別してから深掘りする
- リサーチ結果をタスク・発信に変換し、AIの学習データとしても蓄積する
