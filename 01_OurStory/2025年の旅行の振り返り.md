# 2025年の旅の振り返り

2025年は「過去一最も旅行をした年」として、**3つの大きな旅行期間**と、それに伴う**ステータス修行（ホテル、航空）**、**コンテンツの企画**を実行しました。

---

## 2025年の旅の全体像と期間

2025年は、大きく分けて以下の3つの期間で海外/国内旅行が実行されました。

| 期間 | 旅の分類 | 目的地/内容 |
| :--- | :--- | :--- |
| **春の旅** | 1月30日〜5月15日 | マルタ、イタリア（ミラノ）、ベトナム（ダナン、ホイアン） |
| **夏のヨーロッパ旅** | 7月1日〜11月11日 | ポルトガル（リスボン、ポルト）、シチリア（パレルモ）、トルコ（イスタンブール）、イタリア（ミラノ）、ベトナム（ハノイ、ハロン湾） |
| **冬の旅（修行継続）** | 11月26日〜12月24日 | 北陸（富山、金沢）、韓国（ソウル） |

---

## 1. 春の旅（1月30日〜5月15日）

- **目的地**：マルタ共和国、イタリアのミラノ、ベトナムのダナンとホイアン
- **活動の軸**：主に**マリオットのQ1プロモーション**を利用した宿泊修行

### マルタ共和国

- コロナ禍にトルコのボドルムに滞在した際、マルタに行きたいと考えていた
- 富裕層の居住権や暗号通貨、温暖な地中海の気候に興味があった
- 1月・2月の冬に滞在したが、地中海の気候は温暖で、薄いジャケットで過ごせた
- **マルタでの宿泊**：新しいホテルの**アルバイ マリオット**の現金価格が安かったことが、マリオットのQ1プロモーション修行のきっかけとなった

### イタリア（ミラノ）

- マルタの後に訪れ、初めてのミラノ滞在は非常に思い出深く、3泊のみだったが気に入った
- 治安の悪さが懸念されていたが、2回訪問して特に悪さを感じなかったため、改善されていると感じた

### ベトナム（ダナン、ホイアン）

- 春の旅の目的地に含まれていた

### 達成事項

この期間の修行を含め、**チタンステータス**（2人分）を取得しました。

## 2. 夏のヨーロッパ旅（7月1日〜11月11日）

- **目的地**：パリ（シャルル・ド・ゴール経由）、ポルトガル（リスボン、ポルト）、シチリア（パレルモ）、トルコ（イスタンブール）、イタリア（ミラノ）、ベトナム（ハノイ、ハロン湾）
- **移動手段**：ベトナム航空の**ビジネスクラス**（フルフラットの席）を利用。全行程ビジネスでの移動は「一つの達成」であった

### ポルトガル

- ゴールデンビザや不動産投資ビザに関心があったが、コロナ禍を経て解約されていた
- リスボンとポルトの郊外を含む3拠点で約1ヶ月間滞在
- パリでの欠航により5泊はパリ（シャルル・ド・ゴール近く）での滞在となった
- ご飯も美味しく、良い国であったが、マルタやシチリアと比較すると物価は若干高い印象

### アムステルダム

- ポルトガルの後、アムステルダムに1泊の短期旅行で友人に会いに行った

### シチリア（パレルモ）

- ポルトからイベリア航空のビジネス（現金購入、片道約5万円）でマドリード経由で移動
- **パレルモに1ヶ月間**（エアビーアンドビー、1泊1万円程度）滞在
- パスタやシーフードが非常に美味しく、ヨーロッパの中では最も物価が安い部類だった
- 夏の日本を脱出し、カラッとした気候で非日常的な体験ができた（最高気温は通常26〜27度、一時的に33度程度）
- 東海岸への2泊4日の旅（デルタホテルなど）も実施

### トルコ（イスタンブール）

- **親孝行旅**として初めて海外旅行に行く両親を日本から招待し、1週間滞在
- 両親の初海外旅行を成功させ、非常に喜んでもらえた
- この旅は、これまでのポイント収集やホテル攻略の知識の集大成。宿泊はポイントをフル活用し、チタンステータスの恩恵（アップグレード、朝食など）を受けた
- 初めてヨーロッパ側（市内のメインの場所）に滞在し、じっくり見ることができた
- トルコリラの暴落とインフレにより、日本人から見てさほど安い国ではなくなったとの認識

### イタリア（ミラノ）

- トルコの後に再度訪問し、合計で約2週間弱（3泊と9泊）滞在
- ホテルの宿泊費が高いことや、円安の影響を感じ、稼げるようになる必要性を再確認

### ベトナム（ハノイ、ハロン湾）

- ミラノから移動し、今回は北ベトナムが中心
- ハノイには約12〜13年ぶりに滞在
- **ハロン湾**では、**ハイアット プレイス**で**グローバリスト修行**（40泊を60泊に延長）を実施し、非常にリーズナブルな価格で良質な滞在ができた
- 11月まで滞在し、10月は過ごしやすい気候だったが、途中から秋模様で寒くなる日もあった

## 3. 冬の旅（11月26日〜12月24日）

- **目的地**：北陸（富山、金沢）、韓国（ソウル）
- **活動の軸**：IHGとハイアットの修行の継続

### 韓国（ソウル）

- ワンハーモニーの無料宿泊バウチャー（5万円相当、翌年2月期限）を使うため、急遽予定に追加
- IHG（40泊）とハイアット（グローバリスト60泊）の修行を兼ねている
- 宿泊予定ホテル：
  - シーラホテルソウル（ワンハーモニーのバウチャー利用）
  - JWマリオットソウル（ホテルコレクション）
  - グランドインターコンチネンタルソウル（FHR）

### 北陸（富山、金沢）

- 富山は当初1週間の予定だったが、変更により1泊のみとなった
- 金沢は12泊滞在予定
- 金沢での宿泊はハイアット（ハイアット プレイス、ハイアット ハウス、ハイアット セントリック）が中心で、特にハイアット セントリックではホテルコレクションを4回利用

## 旅の目的と活動（修行・特典活用）

### ホテル修行

| ホテルチェーン | 内容 |
| :--- | :--- |
| **マリオット** | マルタからのQ1プロモーションを利用して**チタンステータスを2人分取得** |
| **ハイアット** | ハロン湾でのロングステイを利用して**グローバリスト修行**（60泊）を実施中 |
| **IHG** | ソウルでの滞在等で**40泊の修行**を達成したい意向 |

### 航空修行

- **ANA SFC修行**：年始（1月5日〜2月頃）に国内線（沖縄、仙台メイン）や国際線（アシアナ中心）を利用して実施し、2月には終了予定
- **マイル活用**：
  - キャセイパシフィックやハワイアン、アラスカマイルを交換し、香港経由でミラノまでの往復をマイルで取得
  - KLM（アメックスポイント使用）や大韓航空（デルタマイル使用）など、特典航空券を積極的に利用

### カード特典活用

- アメックスのポイントやマリオットポイントを活用した宿泊
- **FHR**（ファインホテルアンドリゾート）や**ホテルコレクション**といったVIP優待を受けられるホテルを体験し、使い勝手をコンテンツ化

## コンテンツ制作と情報発信

これらの旅の記録は、フォロワー向けの情報発信の基礎となります。

### ニュースレターの開設

年末までにニュースレターを正式に開設し、Instagramでは伝えきれない、より価値の高いコンテンツを発信する予定。

### コンテンツのテーマ

- 自分たちの旅のストーリーやエピソード（ビハインド）
- アメックスカードの使い方、ポイント交換、マイル利用、ホテル優待の利用体験（FHR、ホテルコレクション）
- ANA SFC修行の活用法
- ホテル4大チェーン（マリオット、ヒルトン、ハイアット、IHG）の攻略と比較
- 複数人での家族旅行におけるマイルやホテルの攻略法（親孝行旅の経験を含む）

### コンテンツの形式

- 有料ノート記事
- 無料記事
- ニュースレター（HTMLデザインを使用）
- デジタル日記や音声記録をベースに作成
