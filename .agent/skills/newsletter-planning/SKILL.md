# Newsletter Planning Skill

## 🎯 概要

このスキルは、ニュースレター作成の**Phase 1: 企画・準備**をサポートします。

**使用タイミング:**

- 新しいニュースレターのテーマを決める時
- 構成と文字数配分を設計する時
- 読者ニーズに合った内容を企画する時

**所要時間目安:** 約 2 時間（配信 3-4 日前に実施）

---

## 📋 企画フレームワーク

### Step 1: テーマ決定（30 分）

以下の 3 つの観点からメインテーマを決定する：

1. **タイミング要因**

   - 期限が迫っているキャンペーン・改定情報
   - 季節イベント（年末年始、GW、夏季など）
   - 直近で発表された重要ニュース

2. **読者ニーズ**

   - DM やメール返信で寄せられた質問
   - Instagram での反応が良かったテーマ
   - 読者が「今すぐ行動すべき」情報

3. **独自性**
   - 自分たちの体験を共有できるテーマ
   - 他のメディアにはない視点を提供できるか
   - 旅行・ホテル・SFC 修行との連携

**チェックリスト:**

- [ ] 今週のニュース・キャンペーンを確認したか
- [ ] 読者からの質問・リクエストを確認したか
- [ ] 旅行体験談の素材を確認したか
- [ ] メインテーマを 1 つに絞ったか

---

### Step 2: 情報収集（1 時間）

収集した情報を**3 段階の重要度**で分類する：

| 重要度マーク | 意味   | 基準                                                 |
| ------------ | ------ | ---------------------------------------------------- |
| 🔥🔥🔥       | 最重要 | 読者が**今すぐ行動すべき**情報（期限迫る、大型変更） |
| 🔸🔸         | 重要   | 読者が**知っておくべき**情報（近日中に影響）         |
| ⭐⭐⭐       | 参考   | 読者が**参考にできる**情報（将来的に影響）           |

**カテゴリ別整理:**

- 💳 決済・ポイント
- 🏦 銀行・金融
- ✈️ エアライン
- 🏨 ホテル

**チェックリスト:**

- [ ] ニュースソースから今週の情報を抽出したか
- [ ] カテゴリ別に分類したか
- [ ] 重要度を 3 段階で分類したか
- [ ] 各ニュースの URL を確認したか

---

### Step 3: 構成設計（30 分）

#### 標準セクション構成

| セクション         | 絵文字 | 目標文字数     | 目的                                       |
| ------------------ | ------ | -------------- | ------------------------------------------ |
| 今週のまとめ       | 📝     | 200-300 字     | 読者が 5 秒で全体像を把握できる            |
| 今週の注目ニュース | 📰     | 800-1,200 字   | 読者が「今すぐ行動すべきか」を判断できる   |
| メインコンテンツ   | 🎯     | 1,000-1,500 字 | 読者が「深く理解できる」「実践できる」内容 |
| 旅行の舞台裏       | 🧳     | 500-800 字     | 読者が「共感できる」「参考になる」体験談   |
| 編集後記           | ✏️     | 300-500 字     | 読者が「次も読みたい」と思える             |

**合計目標: 2,500-3,500 字**

#### ハイライト 3 つの選定

「今週のまとめ」で提示する 3 つのハイライトを決定：

```
✅ **[ハイライト1]** → [簡潔な説明]
✅ **[ハイライト2]** → [簡潔な説明]
✅ **[ハイライト3]** → [簡潔な説明]
```

**選定基準:**

- メインコンテンツへの導線となるものを必ず 1 つ含める
- 期限の迫った重要ニュースを優先
- 旅行関連の体験談を 1 つ含める
