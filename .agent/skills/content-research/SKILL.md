# Content Research Skill

## 🎯 概要

このスキルは、ニュースレター作成の**Phase 2: 情報収集**をサポートします。

**使用タイミング:**

- 企画（Phase 1）完了後、ドラフト作成（Phase 3）前
- 最新のニュース・キャンペーン情報を収集する時
- 収集した情報を検証・整理する時

**所要時間目安:** 約 1-2 時間

**前提スキル:** `newsletter-planning` で企画が完了していること

---

## 📊 情報収集フレームワーク

### Step 1: 情報源の確認（15 分）

#### 主要情報源

| 情報源                       | 用途                       | 更新頻度     |
| ---------------------------- | -------------------------- | ------------ |
| **Excel トラッキングシート** | キャンペーン・ニュース管理 | 都度         |
| **公式サイト**               | 一次情報の確認             | 発表時       |
| **X（Twitter）**             | 速報・口コミ情報           | リアルタイム |
| **プレスリリース**           | 企業発表の正式情報         | 発表時       |

#### Excel ファイルの確認

```
03_NewsLetter/金融機関ニュース_キャンペーン情報_*.xlsx
```

このファイルから今週の対象ニュースを抽出する。

---

### Step 2: カテゴリ別情報収集（30-45 分）

各カテゴリについて、以下の情報を収集：

#### 💳 決済・ポイント

- クレジットカードキャンペーン
- ポイント交換レート変更
- 電子マネー・決済サービスの更新
- 新規入会キャンペーン

#### 🏦 銀行・金融

- 金利変更情報
- 銀行キャンペーン
- NISA・投資関連
- 口座開設特典

#### ✈️ エアライン

- マイルプログラム変更
- 燃油サーチャージ
- 新規路線・運休情報
- 予約システム変更

#### 🏨 ホテル

- ステータスプログラム変更
- 新規開業・改装
- キャンペーン・セール
- 会員特典の更新

---

### Step 3: 情報の検証（30 分）

収集した各情報について、以下を検証：

#### URL 検証チェックリスト

- [ ] URL が正しく開くか確認
- [ ] リンク先の内容が記載情報と一致するか
- [ ] 短縮 URL（bit.ly 等）の場合、リダイレクト先を確認

#### 日付・期限の検証

- [ ] 開始日と終了日が正しいか
- [ ] 配信日時点で有効な情報か
- [ ] 期限が近い場合、正確な時刻も確認（例：18:00 まで）

#### 数値・金額の検証

- [ ] 還元率、ポイント数が正しいか
- [ ] 上限金額、条件が正確か
- [ ] 複数の情報源で整合性を確認

#### 条件の検証

- [ ] 対象者の条件が明確か（新規/既存、年齢等）
- [ ] 必要な手続き（エントリー、登録等）を明記
- [ ] 除外条件や注意事項を把握

---

### Step 4: 情報の整理（15 分）

収集・検証した情報を Markdown テーブル形式で整理：

```markdown
### 💳 決済・ポイント

| ニュース                               | 期限・開始              | 重要度 |
| -------------------------------------- | ----------------------- | ------ |
| **[タイトル](URL)** 説明文（条件など） | YYYY 年 MM 月 DD 日まで | 🔥🔥🔥 |
| **[タイトル](URL)** 説明文             | YYYY 年 MM 月 DD 日から | 🔸🔸   |
```

---

## 📋 出力テンプレート

`resources/news_collection_template.md` を使用して整理する。

### 必須項目

各ニュースに必ず含める情報：

1. **タイトル** - 内容が一目でわかる見出し
2. **URL** - 公式情報へのリンク
3. **説明文** - 1-2 文で要点を説明
4. **期限/開始日** - 具体的な日付
5. **重要度** - 3 段階マーク

### 重要度の判定

`../newsletter-planning/resources/importance_criteria.md` を参照：

| 重要度 | 基準                                   |
| ------ | -------------------------------------- |
| 🔥🔥🔥 | 7 日以内に期限 or 年間数万円以上の影響 |
| 🔸🔸   | 1 ヶ月以内に対応必要                   |
| ⭐⭐⭐ | 将来的に重要、参考情報                 |

---

## ✅ 完了チェックリスト

Phase 2 完了時に以下を確認：

- [ ] 全カテゴリの情報を収集した
- [ ] 全ての URL が動作確認済み
- [ ] 日付・金額が検証済み
- [ ] 重要度が適切に設定されている
- [ ] Markdown テーブル形式で整理されている
- [ ] ニュースの個数が適切（各カテゴリ 2-5 個程度）
