# 情報検証チェックリスト

ニュースレターに掲載する全ての情報について、以下の検証を実施する。

---

## 🔗 URL 検証

### 基本チェック

- [ ] URL をクリックしてページが正常に開くか
- [ ] 404 エラーや「ページが見つかりません」が表示されないか
- [ ] リダイレクトされる場合、最終的な遷移先は適切か

### 短縮 URL（bit.ly 等）の場合

- [ ] 元の URL を確認（bit.ly/[code]+ で確認可能）
- [ ] 短縮 URL の有効期限を確認
- [ ] 公式の短縮 URL か、自作のものかを明記

### リンク先の内容確認

- [ ] リンク先のページ内容が記載情報と一致するか
- [ ] キャンペーンページの場合、期間が表示されているか
- [ ] 公式サイトのドメインからのリンクか（フィッシング対策）

---

## 📅 日付・期限の検証

### 基本チェック

- [ ] 開始日が正しいか
- [ ] 終了日が正しいか
- [ ] 配信日時点で有効な情報か（期限切れではないか）

### 詳細チェック

- [ ] 時刻まで重要な場合（例：18:00 終了）は時刻も記載
- [ ] 「〜まで」「〜から」の表現が適切か
- [ ] 複数の期限がある場合（申込期限、利用期限など）を区別

### 日付フォーマット

推奨フォーマット：

- 年月日：「2026 年 1 月 15 日」または「2026/1/15」
- 期間：「〜2026 年 1 月 31 日」「2026 年 1 月 1 日〜3 月 31 日」

---

## 💰 数値・金額の検証

### 還元率・ポイント

- [ ] 還元率（%）が正確か
- [ ] ポイント数が正確か
- [ ] 上限ポイント/金額が明記されているか

### 金額

- [ ] キャンペーン金額が正確か
- [ ] 税込/税抜の区別が明確か
- [ ] 条件達成に必要な金額が正確か

### 計算例

- [ ] 具体的な計算例を提示する場合、計算が正しいか
- [ ] 複数の特典を組み合わせる場合、合計が正確か

---

## 📋 条件の検証

### 対象者

- [ ] 新規/既存会員の区別が明確か
- [ ] 年齢制限がある場合、明記されているか
- [ ] 特定のカード保有者限定などの条件を確認

### 必要な手続き

- [ ] エントリー/登録が必要な場合、明記
- [ ] エントリー期限がある場合、明記
- [ ] 手続きの URL やアプリを案内

### 除外条件

- [ ] 対象外となるケースを確認
- [ ] 併用不可の特典がある場合、注意喚起
- [ ] 月間/年間の上限がある場合、明記

---

## ✅ 最終確認

全ての情報について以下を確認：

| 項目                 | チェック |
| -------------------- | -------- |
| URL 動作確認         | ☐        |
| 日付の正確性         | ☐        |
| 数値の正確性         | ☐        |
| 条件の明記           | ☐        |
| 重要度の適切さ       | ☐        |
| 説明文の分かりやすさ | ☐        |

---

## ⚠️ よくあるミス

1. **期限切れキャンペーン** - 配信日に既に終了しているものを掲載
2. **古い情報** - 改定後も改定前の情報を掲載
3. **条件の見落とし** - 「要エントリー」などの条件を見逃す
4. **URL リンク切れ** - キャンペーン終了でページが消える
5. **計算ミス** - 複数特典の合計値の計算間違い
