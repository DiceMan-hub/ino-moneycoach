# Newsletter Format Standardization Skill

## 🎯 概要

このスキルは、ニュースレター作成の**Phase 3-4: 表記統一**をサポートします。

**使用タイミング:**

- Markdownドラフト作成時
- HTML変換時
- 整合性チェックで不一致が見つかった時

**所要時間目安:** 約 10 分（手動）→ 自動化により 0 分に短縮可能

**前提スキル:** `content-research` で情報収集が完了していること

---

## 📋 表記統一フレームワーク（Vol.07実績ベース）

### Rule 1: FSG（フリーステイギフト）表記

**Vol.07で確立したルール:**

| 出現順序 | 表記 |
|----------|------|
| **初出時** | アメックスのフリーステイギフト（FSG） |
| **2回目以降** | FSG |
| **補足が必要な場合** | FSG（アメックスのフリーステイギフト） |

#### 適用例（Vol.07実績）

**初出時:**
```markdown
Vol.06では「視察報告」として要点をお伝えしましたが、今回は**「実際にアメックスのフリーステイギフト（FSG）で泊まる前に知っておくべき全て」**をnote記事にまとめました。
```

**2回目以降:**
```markdown
特に、**「FSG利用不可期間の完全リスト」**、**「時期別価格相場の詳細分析」**など...
```

**補足が必要な場合:**
```markdown
**「FSG（アメックスのフリーステイギフト）利用不可期間の完全リスト」**
```

### Rule 2: ホテル名表記

**Vol.07で確立したルール:**

| ホテル | 正式表記 | 短縮表記（本文中） |
|--------|----------|-------------------|
| ハイアット瀬良垣 | ハイアット リージェンシー 瀬良垣（沖縄） | ハイアット リージェンシー 瀬良垣 |

#### 適用箇所

- **タイトル**: 正式表記を使用（「沖縄」を含める）
- **ハイライト**: 正式表記を使用
- **CTAボタン**: 正式表記を使用
- **目次**: 正式表記を使用
- **本文**: 短縮表記も可（文脈による）

#### 適用例（Vol.07実績）

**タイトル:**
```markdown
【新作note公開】ハイアット リージェンシー 瀬良垣（沖縄）アメックスフリーステイギフト完全攻略ガイド
```

**本文:**
```markdown
Vol.06で「視察報告」として要点をお伝えした**ハイアット リージェンシー 瀬良垣アイランド 沖縄**。
```

### Rule 3: #PRタグ

**Vol.07で確立したルール:**

| サービス | #PRタグ | 理由 |
|----------|---------|------|
| TopCashback | ✅ 必要 | アフィリエイトリンク |
| Wise | ✅ 必要 | アフィリエイトリンク |
| マリオットボンヴォイアメックス | ❌ 不要 | Vol.07で削除 |
| ヒルトンアメックス | ❌ 不要 | Vol.07で削除 |

#### HTML形式

```html
<a href="URL" style="color: #14c1bd; text-decoration: underline;">サービス名</a><span style="font-size: 10px; color: #999; margin-left: 4px;">#PR</span>
```

#### Markdown形式

```markdown
[サービス名](URL) #PR
```

### Rule 4: リンク色の統一（Vol.07で修正）

**重要:** Vol.07で、SBIハイパー預金のリンクが赤色だったため、`#14c1bd`に統一した経緯あり。

| 要素 | カラー | 注意 |
|------|--------|------|
| **通常リンク** | `#14c1bd` | 赤色は使用しない |
| **CTAボタン背景** | `#14c1bd` | |
| **CTAボタンテキスト** | `#ffffff` | |

**NG例:**
```html
<a href="URL" style="color: #e53935;">タイトル</a>  <!-- 赤色は使用しない -->
```

**OK例:**
```html
<a href="URL" style="color: #14c1bd; text-decoration: underline;">タイトル</a>
```

---

### Rule 5: CTAボタン

**Vol.07で確立したルール:**

- **矢印**: 必ず「→」を末尾に追加
- **配置**: 中央揃え
- **テキスト**: タイトルを含める（長い場合は `font-size: 12px` + `line-height: 1.4`）

#### スタイル

**冒頭の小さめCTAボタン:**
- 背景色: `#14c1bd`
- パディング: `10px 20px`
- フォントサイズ: `12px`
- ボーダー半径: `4px`

**後半の大きなCTAボタン:**
- 背景色: `#14c1bd`
- パディング: `14px 32px`
- フォントサイズ: `15px`
- ボーダー半径: `6px`

### Rule 6: 日付・期限表記

| 形式 | 例 |
|------|-----|
| **期限** | 申し込み：4月14日まで |
| **開始日** | 1月13日開始 |
| **期間** | 2026年1月〜9月 |
| **発表日** | 1月13日発表 |

#### 配置

HTMLテーブルでは、日付をタイトル下に小さめのフォントで配置：

```html
<td style="padding: 10px 12px; border: 1px solid #e0e0e0; vertical-align: top">
  <a href="URL" style="color: #14c1bd; text-decoration: underline;">タイトル</a>
  <div style="font-size: 11px; color: #888; margin-top: 4px;">申し込み：4月14日まで</div>
</td>
```

## 💡 Vol.07で学んだ教訓

1. **FSG表記**: 「FSG」だけでは読者に伝わらない。初出時に「アメックスのフリーステイギフト（FSG）」と明記する
2. **ホテル名**: 「ハイアット瀬良垣」だけでは場所が分からない。「（沖縄）」を追加する
3. **リンク色**: 赤色リンクが混在していたため、全て `#14c1bd` に統一した
4. **#PRタグ**: マリオット・ヒルトンは自社カードのため#PRタグを削除
5. **CTAボタン**: 矢印（→）を追加することで、リンクであることが明確になる
