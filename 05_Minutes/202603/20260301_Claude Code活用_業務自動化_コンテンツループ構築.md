# 会議議事録：Claude Code活用 業務自動化・コンテンツループ構築

**日時:** 2026年3月1日
**場所:** マレーシア（クラブ滞在中）
**議題:** Claude Codeを活用した業務の棚卸しと自動化、リサーチ〜コンテンツ作成のループ構築、PR案件のコンバージョン向上、AIによるプロジェクトマネジメントとプラン策定

---

## 1. AI（Claude Code）を活用した業務の棚卸しと時短の実験

### 現状の取り組み
- 現在行っている作業の棚卸しを行い、Claude Codeを用いて時短できるものから順次、自動化の実験を行っている。
- 具体的には、Claude Codeに「スキルズ（Skills）」を作成させ、毎日の特定分野のリサーチ（定点観測）を自動で行わせる検証を進めている。
- うまくいけば即座に時短効果が生まれるため、まずは実験的に運用し、将来的にはチーム全員で活用できる体制を目指す。

## 2. リサーチからコンテンツ作成までの「自動化ループ」構築

### リサーチと分析の自動化
- **アプローチ:** 競合（今ちゃん等）のようにYouTube等で伸びているものを分析する手法と、自社アカウントの過去のインサイトから伸びたものを深掘りする手法の両方を試みるが、まずは自社の軸に沿った慣れている手法から進める。
- **API連携によるインサイト取得:** Meta SuiteのGraph APIを利用してClaude Codeと連携させることで、インサイト分析、DM対応、DM内容のデータ化（表まとめ）などを自動化できる可能性がある（API利用のリスクは低いと調査済み）。
- X（旧Twitter）などを目視でリサーチする時間を減らすことが、最初の大きな時短に繋がる。
- インサイト（現在はLooker Studioやスプレッドシートで一部確認）をAIに定期的に分析させ、週1〜2回のレポートとして自動提出させることで、課題や改善案（次回のネタ収集の方向性など）が自動で提示されるループを作る。

### コンテンツ制作の切り分け（ベルトコンベア化）
- 自動収集したネタをもとに、AI（別エージェント）に投稿の題材やテキストベースの構成を順番に作らせる。
- 最終的なデザイン（Figma等へのコーディング）の完全自動化はまだ難しいため、**「自分たちの色があまり出ないライトなコンテンツ（ニュース等）」は自動化**し、**「自分たちの経験談やホテルレビューなどのヘビーなコンテンツ」には人間が時間をかけて作る**という切り分けを行う。

## 3. PR（アフィリエイト等）の出口戦略とコンバージョン向上

### 一貫した導線と教育
- どれだけAIでコンテンツを量産しリーチを広げても、PR案件（出口）への繋ぎ方や売り文句が下手では売上には繋がらない。
- 「ぽいっとさん」などの成功事例を参考に、ハイキャッチな画像構成やタイトルの付け方、出口まで誘導するメッセージの仕掛けを言語化・定義し、AIのスキルに落とし込む必要がある。
- 投稿内で教育してハイライトへ誘導するか、DMで教育して申し込みへ誘導するか、いずれにせよ「ユーザーを惹きつけ、最後まで申し込みを完了させる」一貫した導線が不可欠である。
  - *成功事例:* 先日のPR案件では、紹介リンク利用者の61%が申し込みを完了しており、この導線設計はうまくいっていると評価。

### リソースの再配分
- 時間の掛からない作業はAIによる自動化ループに組み込み、そこで浮いた時間を「いかにコンバージョンレート（成約率）を上げるか」という丁寧なクリエイティブ制作や仕組み作りに集中投下する。

## 4. AIによるプロジェクトマネジメントとグランドプラン策定

### 3ヶ月のグランドプラン作成
- 過去の議事録などのデータをAIに読み込ませることで、現状の課題に基づいた「3ヶ月のグランドプラン（目標とロードマップ）」を数十分で自動作成させる仕組みを構築中。
- このグランドプランから逆算し、「1ヶ月」「今週」「今日やるべきこと」をAIに細かく提示（プロジェクトマネジメント）させる。

### データドリブンな判断と優先順位付け
- グランドプラン策定で最も重要なのは、「どのPR案件（単価、訴求しやすさ）をメインに据えるか」である。
- 既に作成済みの「アフィリエイト案件リスト」と、過去のコンバージョン実績などのデータをAIに学習させることで、案件ごとの目標値や最適な訴求パターンを瞬時に立案させる。
- 突発的なニュースやタスクが発生した場合も、AIにデータと照合させて優先順位を判断させることで、人間がマニュアルで管理するよりも確実かつ楽に進行できる。

## 5. Next Steps（今後の進め方）
- まずは1日1回、AI（Claude Code等）を使って「今何をやっているか」を共有し、チームで確認する。
- AIの出力が最初は不完全（間違える可能性）であっても、「圧倒的な時短（時間を買うこと）」を優先して実験を進め、浮いた時間で少しずつ軌道修正・ブラッシュアップを行い、最終的な売上アップを目指す。
