予約の方法・利用の流れ・ルール（2025→2026 変更なし）

予約方法・利用方法・ルール・注意事項に変更はありません。以下は2026年度版に沿った要点です。

  • 予約：各ホテルの予約窓口に電話し、「アメリカン・エキスプレスのフリー・ステイ・ギフト宿泊券を利用する」と伝える。予約前にカードと宿泊券を用意。
  • 利用の流れ：チェックイン時にカードを呈示し、宿泊券にサインしてフロントに渡す。
  • ルール・注意の要点：1泊食事なしプラン。記載の客室タイプが対象。会員本人または家族カード・追加カード会員本人の宿泊のみ。転売・譲渡不可。解約済みのカードでは利用不可。有効期限はチェックイン期限（予約期限ではない）。宿泊券の再発行・複写は不可。キャンセル・変更は各ホテル指定の期限内に手続き。2泊目クレジットは「【2泊目】5,000円分」とあるホテルで2連泊以上予約した場合に適用（窓口予約が条件、第三者経由は対象外）。

参考：プラチナ・カード（およびANAアメリカン・エキスプレス・プレミアム・カード、ビジネス・プラチナ・カード）のFSGではヒルトン系ホテルが対象に含まれます。

今回の変更の評価

1. 変更の全体像

  • 件数：追加6・除外8で実質2件減。選択肢はわずかに絞られる。
  • ブランド別：ヒルトン系が純増（+2）でキャノピー梅田・宮古島が加わった。西武プリンス・ロイヤルパークは同数。マリオット・オークラニッコー・ハイアットは減。

2. 利用者視点でのメリット

  • ヒルトン系：キャノピーbyヒルトン大阪梅田・沖縄宮古島が新規追加。プラチナFSGではヒルトン・オナーズ特典と併用できるため、梅田の都心1泊や宮古島リゾートの選択肢が増えた。
  • 福岡・名古屋：福岡プリンスももち浜（2026年3月開業予定）・コートヤード名古屋が追加。九州・中部の都市・リゾートでFSGを使いやすくなった。
  • 舞浜・那覇：ロイヤルパーク舞浜・那覇アイコニックが新規。ディズニー周辺や那覇都心の立地重視の選択肢が増えた（いずれも2泊目クレジットは対象外）。
  • ルール：予約方法・利用条件・2泊目クレジットのルールに変更なし。

3. 利用者視点でのデメリット・注意点

  • 除外されたホテル：ルスツ・京都宝ヶ池・オークラ東京ベイ・キャプションなんば・瀬良垣沖縄・ロイヤルパーク名古屋・京都など。リゾート・都市の一部選択肢が減った。
  • マリオット・ハイアット：アロフト銀座・ウェスティンルスツが除外。ハイアットなんば・瀬良垣が除外され、会員特典を併用してメリットを出せるホテルが一部減少。
  • 2泊目クレジット：追加6件のうち舞浜・那覇アイコニックは対象外。連泊で5,000円クレジットを狙うなら他4件を選ぶ必要がある。

4. まとめ

  • ヒルトン系の追加が目立つ変更。都市型（梅田・名古屋）とリゾート（福岡・宮古島・舞浜・那覇）の新規がバランスよく入り、除外はリゾート・都市の一部に集中。利用条件・ルールは変わっていないため、対象ホテルリストの入れ替えとして把握し、自分の利用パターンに合うかで判断するとよい。
