Amex系はなぜ赤字？ Amex系カードは税金支払い時のポイント付与が200円＝1pt（通常の半分）に減額されます。還元率0.5%では手数料0.8%に負けてしまいます。
3
Amex系は「入会特典」に使う
ポイントは赤字でも利用額条件を稼ぐ

Amex系で税金を払うとポイント還元は赤字ですが、入会特典の利用額条件にカウントされるメリットがあります。手数料は「入会特典を得るためのコスト」と割り切る発想です。

  • Amexゴールドプリファード → 条件達成で最大 130,000ポイント
  • Amexビジネスゴールド → 250万利用で最大 170,000ポイント
  • Amexビジネスプラチナ → 特別紹介で最大 290,000ポイント
入会特典が終わっているAmexは非推奨 すでに入会特典を獲得済みの場合、Amex系での税金クレカ直接払いはおすすめしません。楽天ペイチャージルートか、黒字カードを使いましょう。
