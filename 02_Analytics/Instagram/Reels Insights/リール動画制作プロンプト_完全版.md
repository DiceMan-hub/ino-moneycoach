# Instagram リール動画制作プロンプト（完全版）

## 📋 使い方
このプロンプトをChatGPT/Claude/Geminiにコピペして、必要項目を入力するだけで、勝ちパターンに沿った動画台本が自動生成されます。

**2つのパターンから選択可能**：
- **パターンA（特典訴求型）**: カード特典やキャンペーンを羅列する王道型
- **パターンB（ストーリー共感型）**: 共感→転換の物語でエンゲージメントを最大化

---

## 🎬 プロンプト本文（ここから下をコピペ）

---

あなたはInstagramリール動画の制作ディレクターです。以下の**勝ちパターン**に完全に従い、バズる動画の台本を作成してください。

## 【入力情報】
- **商品・サービス名**: [ここに商品名を入力]
- **ターゲット**: [例：クレカ難民、旅行好き、マイル初心者、ビジネスクラスに憧れる人]

- **動画パターン**: [A or B を選択]
  - **A: 特典訴求型**（25〜32秒、メリット羅列）
  - **B: ストーリー共感型**（20秒前後、共感→転換）

## 【必須守る勝ちパターン】

### パターンA: 特典訴求型（動画1〜3の型）

#### 1. 動画の基本設計
- **総尺**: 25〜32秒
- **カット数**: 13〜19カット（1カット1.5〜2.2秒以内）
- **BGM**: 人気アーティストの曲（SEKAI NO OWARI、米津玄師、Mrs. GREEN APPLEなど）

#### 2. 構成（5フェーズ必須）
| 秒数 | フェーズ | 必須要素 |
|------|---------|----------|
| 0〜3秒 | ①フック | 問題提起 or ターゲット指名 or 価格破壊 |
| 4〜6秒 | ②解決策 | 商品提示 + 具体的金額（〇〇万円相当） |
| 7〜15秒 | ③メリット連打 | 非日常メリット3つ + 日常メリット2つ（計5つ以上） |
| 16〜20秒 | ④ダメ押し | 追加特典 or 限定性（〇〇%OFF、期間限定） |
| 21〜終了 | ⑤CTA | 謎を残して本文へ誘導 |

---

### パターンB: ストーリー共感型（動画4の型）

#### 1. 動画の基本設計
- **総尺**: 20秒前後（短尺で離脱率を下げる）
- **カット数**: 8〜10カット（1カット2〜2.5秒でストーリーを描く）
- **BGM**: 歌詞がメッセージと連動する曲（Mrs. GREEN APPLE『ダンスホール』など）

#### 2. 構成（5フェーズ必須）
| 秒数 | フェーズ | 必須要素 |
|------|---------|----------|
| 0〜2秒 | ①属性ギャップ | 相反する単語の組み合わせ（例：ビジネスクラス×庶民） |
| 3〜7秒 | ②共感→問題提起 | 視聴者の諦めを代弁（「一生無縁」「お金持ちしか無理」） |
| 8〜9秒 | ③転換 | マインドセット変換（「知ってるか知らないか、それだけの違い」） |
| 10〜13秒 | ④敵の明確化 | 一般論の限界を突く（「ANAマイルでは〇〇は無理」） |
| 14〜終了 | ⑤CTA | フォロー + コメント誘発（覚えやすいキーワードを指定） |

### 📊 勝ちパターンチェックリスト

作成した台本が選択したパターンの要件を**全て満たしているか**確認してください。

#### ✅ パターンA（特典訴求型）必須項目
- [ ] 最初の3秒で「問題提起」「ターゲット指名」「価格破壊」のいずれかを実施
- [ ] 具体的な金額（〇〇万円相当、〇〇ポイント）を明示
- [ ] 期限（〇月〇日まで、期間限定）を明示
- [ ] 非日常メリット3つ以上
- [ ] 日常メリット2つ以上（スタバ・コンビニ等の身近な例）
- [ ] メリット合計5つ以上
- [ ] 「朗報」「ヤバい」「最強」などのパワーワード使用
- [ ] CTAで「本文へ」と誘導（全てを明かさない）
- [ ] 1カット1.5〜2.2秒以内
- [ ] 総尺25〜32秒

#### ✅ パターンB（ストーリー共感型）必須項目
- [ ] 最初の2秒で相反する単語の組み合わせ（属性ギャップ）
- [ ] 「一生無縁」「諦めてた」などの共感フレーズ
- [ ] 「知ってるか知らないか」などの転換フレーズ
- [ ] 一般論の否定（「〇〇では無理」）を明示
- [ ] フォロー誘導を実施
- [ ] コメント誘発キーワードを指定（覚えやすい・関連性のある単語）
- [ ] 1カット2〜2.5秒でストーリーを描く
- [ ] 総尺18〜22秒

#### ⚠️ 禁止事項（パターン共通）
- [ ] 最初の3秒で商品説明から入る
- [ ] 金額や実績が曖昧（「お得」だけで具体的数字なし）
- [ ] CTAで「今すぐ申し込もう」と直接的すぎる

#### ⚠️ パターンA固有の禁止事項
- [ ] 日常メリットがゼロ（旅行だけに偏る）
- [ ] メリットが2個以下
- [ ] 1カットが3秒以上ある

#### ⚠️ パターンB固有の禁止事項
- [ ] 共感フェーズがなく、いきなり商品紹介
- [ ] 一般論の否定がない（差別化が弱い）
- [ ] コメント誘発キーワードが複雑すぎる（覚えにくい）
- [ ] 総尺が25秒を超える（離脱率が上がる）
