# 【完全版】手書きノート型リール PR案件攻略マニュアル

## 📌 このマニュアルの目的

2つの成功動画（飛行機代タダ/スタバ20杯無料）を徹底分析し、**誰でも再現できるフォーマット**にまとめました。このマニュアル通りに制作すれば、PR案件の成約率を劇的に向上させることができます。

---

## 🏆 成功実績サマリー

### 分析した2つの動画

| 項目 | 動画1（HafH） | 動画2（COIN+） |
|------|-------------|--------------|
| **商材** | 旅行サブスク | 金融アプリ |
| **訴求** | 飛行機代タダ | スタバ20杯無料 |
| **総尺** | 58秒 | 52秒 |
| **ターゲット** | 旅行好き | UFJ銀行ユーザー |
| **推定成約率** | 0.1% | 0.45% |
| **特徴** | 夢（旅行）を売る | 現実（節約）を売る |

### 共通する成功要因

1. **手書きノート × ペン誘導** = 58秒でも離脱されない
2. **段階的情報開示** = 好奇心を連続発火
3. **損失回避バイアス** = 最強の動機付け
4. **3層ファネル構造** = 高い成約率

## 7. 損失回避バイアスの活用法

### なぜ「損」が最強なのか？

```
【プロスペクト理論】
人間は「得する」より「損しない」に強く反応する

例：
「100万円得する」 < 「100万円損しない」

この動画での応用：
「スタバ20杯無料（得）」 < 「ATM手数料ゼロ（損しない）」

結果：
→ 「損しない」の方が強力な動機付け
→ 行動率が劇的に上がる
```

### 「損」の使い方

| 使用箇所 | 例文 | 効果 |
|---------|------|------|
| **フック** | 「普通に〇〇使ってたら損してる」 | 即座に注目 |
| **損失回避** | 「これを使わないと〇〇するたびに損」 | 焦燥感 |
| **畳み掛け** | 「知らない人はかなり損してる」 | ダメ押し |

## 8. 恐怖訴求の活用法

```
【心理メカニズム】
1. 損失回避バイアス

2. 情報への依存

3. ガイドを見る必然性

結果：
→ PDFガイドへの誘導率が劇的に上がる
→ 成約率が4.5倍に
```

# 第5部：成功指標と改善

## 13. KPI設定

### 各層のKPI

| 層 | KPI | 目標値 | 測定方法 |
|---|------|--------|---------|
| **リール** | 視聴完了率 | 30%以上 | インサイト |
| **リール** | キャプション遷移率 | 10%以上 | 推定 |
| **キャプション** | ガイド遷移率 | 30%以上 | リンククリック |
| **PDFガイド** | 成約率 | 15%以上 | アフィリエイト管理画面 |
| **全体** | 成約率（リールベース） | 0.45%以上 | 計算 |

### 成功の定義

```
【成功基準】
リール視聴者10,000人あたり45人以上が成約
= 成約率0.45%以上

【計算式】
成約数 = リール視聴者 × 10% × 30% × 15%
       = 10,000 × 0.1 × 0.3 × 0.15
       = 45人
```

---

## 14. 改善ポイント

### 視聴完了率が低い場合

| 問題 | 原因 | 改善策 |
|------|------|--------|
| 0〜4秒で離脱 | フックが弱い | 固有名詞を追加、「損」を強調 |
| 10秒前後で離脱 | 飽きている | イラストを追加、ペン先の動きを速く |
| 30秒前後で離脱 | 興味が薄れた | 損失回避を強化、カップルイラスト追加 |
| 40秒以降で離脱 | 結論を知りたい | 「失敗するよ!!」を強調 |

### 成約率が低い場合

| 問題 | 原因 | 改善策 |
|------|------|--------|
| ガイド遷移率が低い | CTAが弱い | 「プレゼント」を強調、ボタンを目立たせる |
| 成約率が低い | ガイドが分かりにくい | 画像を増やす、失敗例を追加 |
| 成約率が低い | 信頼性が足りない | Q&Aを充実、デメリットも開示 |
