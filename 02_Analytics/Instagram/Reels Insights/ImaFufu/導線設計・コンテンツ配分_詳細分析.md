## 📌 分析の目的

この分析では、**リール動画→インスタグラムキャプション→ブログ記事**という3層構造の導線設計と、各段階でのコンテンツ配分戦略を徹底解剖します。

---

## 🎯 全体導線マップ

```
【入口】Instagramリール（58秒）
    ↓ 「本見てね」
【第2層】Instagramキャプション（約200文字）
    ↓ 「HafH招待リンク」「完全攻略ガイド」

    ↓ アフィリエイトリンク（複数配置）
```

## 2. 導線設計の戦略分析

### 2-1. 情報開示の段階的設計

```
【第1層：リール】15%開示
├─ 結論だけ見せる
├─ サービス名は隠す
└─ 好奇心を最大化

【第2層：キャプション】40%開示
├─ サービス名を開示
├─ キャンペーン概要を提示
└─ ブログへの動機付け

【第3層：ブログ】100%開示
├─ 全ての情報を提供
├─ デメリットも開示
└─ 信頼を獲得して成約
```

### 2-2. 各層の役割分担

| 層 | 役割 | 提供価値 | 心理状態 | 離脱率 |
|---|------|---------|---------|--------|
| **リール** | 集客・興味喚起 | 「タダになる」という結論 | 「え、何それ？」 | 高（40〜60%） |
| **キャプション** | フィルタリング・誘導 | サービス名、キャンペーン概要 | 「もっと知りたい」 | 中（30〜50%） |
| **ブログ** | 教育・信頼・成約 | 完全ガイド、メリット/デメリット | 「やってみよう」 | 低（10〜20%） |

### 2-3. 離脱防止策の比較

| 層 | 離脱リスク | 防止策 |
|---|-----------|--------|
| **リール** | ・長尺（58秒）<br>・情報が少ない | ・ペン先ポインター<br>・スクロール形式<br>・「最後に教える」宣言 |
| **キャプション** | ・文字が多い<br>・ブログへの誘導が弱い | ・絵文字で視覚的に<br>・ボタン形式のCTA<br>・特典（ホテル一覧）提示 |
| **ブログ** | ・文字数が多い（8,000字）<br>・読むのが面倒 | ・目次で構造化<br>・具体例を多用<br>・デメリットも開示（信頼性）<br>・FAQ で不安解消 |

## 5. 導線設計の巧妙さ

### 5-1. 「情報の小出し」戦略

#### なぜ段階的に開示するのか？

```
【心理学的根拠】
1. ツァイガルニク効果
   → 未完了の情報は記憶に残る
   
2. 好奇心の連鎖
   → 少しずつ明かすことで次が気になる
   
3. コミットメントの階段
   → 小さな行動（キャプション閲覧）
   → 中程度の行動（ブログ閲覧）
   → 大きな行動（登録）
```

### 5-2. 各層の「隠す情報」の戦略性

| 層 | 隠す情報 | なぜ隠すか | 効果 |
|---|---------|-----------|------|
| **リール** | サービス名（HafH） | キャプションへ誘導するため | 好奇心を最大化 |
| **キャプション** | 具体的金額（3,240円） | ブログへ誘導するため | 「もっと知りたい」 |
| **ブログ** | なし（全開示） | 信頼を獲得して成約するため | 透明性による信頼 |

### 5-3. 「特典」による誘導設計

```
【リール】
特典なし
↓
「本見てね」だけでは弱い
→ 「最後に教える」で視聴継続

【キャプション】
特典：ホテル一覧プレゼント
↓
ブログに行く理由を作る
→ 「一覧が欲しい」という動機

【ブログ】
特典：完全ガイド、FAQ、裏ワザ
↓
全ての情報を提供
→ 「これだけあれば安心」
```
