# 詳細分析レポート No.2：手書きノート型「スタバ20杯無料×金融サービス訴求」

## 📌 エグゼクティブサマリー

この動画は、動画1（飛行機代タダ）と同じクリエイターによる手書きノート型リールですが、**商材と訴求戦略が大きく異なります**。

### 🎯 最大の特徴
- **52秒の長尺**でありながら高い視聴維持率
- **「得する（スタバ無料）」×「損しない（ATM手数料ゼロ）」のダブル訴求**
- **マス向けターゲット**：UFJ銀行ユーザー（数千万人規模）
- **損失回避バイアス**を最大限に活用した設計

### 📊 核心的な成功要因
1. **国民的ペイン（ATM手数料）への訴求**
2. **「失敗するよ！」という脅しによる依存性の創出**
3. **カップルイラストによる感情的ベネフィット**
4. **UFJ×リクルートという権威性**
