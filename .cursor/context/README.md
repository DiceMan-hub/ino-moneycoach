# Claude Code の「育て方」— 文脈の外部記憶

## なぜこのフォルダがあるか

Claude Code は**セッションごとに記憶がリセット**される。**長いチャットではコンテキストを失うこともある。**  
差がつくのは「使い方」ではなく**「育て方」**＝AIに渡す**文脈の厚み**を意図的に設計し、**会話のうちに記録を残していく**かどうか。

このフォルダは、**判断基準・過去の経緯・嗜好**を「外部記憶」として置き、毎回参照・更新できるようにするためのもの。**コンテキストが切れても、ここに書いてあれば次のセッションで引き継がれる。**

## ファイル構成

| ファイル | 内容 |
|----------|------|
| `01_judgment_criteria.md` | 判断基準の言語化（なぜその判断・意思決定をしたか） |
| `02_past_outcomes.md` | 過去の経緯（何が成功し、何が失敗したか） |
| `03_preferences.md` | 個人の嗜好（心地よいアウトプットのスタイル） |

## エージェント向けの指示

- **タスク開始時**: タスクの性質に応じて、上記1〜3のファイルのうち関連するものを読む。特に意思決定や書き方・フォーマットに触れる場合は必ず参照する。
- **会話の途中で（記録を残す — コンテキスト消失に備える）**:
  - 新しい判断基準・過去の成功/失敗・嗜好が会話で出てきたら、**その場で**「context に残しておきましょうか？」と追記案を提示し、了承されたら**すぐに該当ファイルへ書き込む**。提案だけで終わらせず、**書き残す**ことを優先する。
  - ユーザーが「記録して」「contextに残して」「追記して」と言ったら、該当ファイルにすぐ追記する。
  - 追記時は既存と重複しないようにし、`[YYYY-MM]` や `[VolXX]` を付ける。
- **長い作業の区切り**: 重要な方針や決まったことがあれば、「ここまでを 01/02/03 に残しますか？」と声をかけてよい。
