# 判断基準の言語化

「なぜその判断・意思決定をしたか」を短く書き、AIが同じ基準で動けるようにする。

---

## ニュースレター

- **1号1リンク**: 今号で最も読んでほしいリンクは1つだけ。同じCTAが2〜3号続いたら次号は別の出口を検討。
- **リンク数**: メインCTA（3箇所）＋Instagram＋配信停止を除き、合計5つ以内が理想。ニュース表は見出しを公式URLのテキストリンクにし、表内にリンクを並べない。
- **配信後**: 該当号は必ずアーカイブ。`_working` に溜めない。整理は `newsletter_organize.py` で行い、実行前に `--dry-run` で確認する。

## リポジトリ・運用

- **Git push**: `git push` 実行時は `required_permissions: ["all"]` を使う。Keychain アクセスのため。
- **HTML 配置**: GitHub Pages 用は `/docs/[project-name]/index.html` のみ。`.html` をルートに置かない。
