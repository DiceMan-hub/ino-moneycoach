# 個人の嗜好（アウトプットのスタイル）

自分が心地よいと感じる表現・形式・トーンを書く。AIの出力の質を「自分好み」に近づけるため。

---

## 言語・トーン

- **応答言語**: 明示されない限り日本語で応答する。
- **説明**: 簡潔に。必要以上に前置きや挨拶を増やさない。結論や手順を先に。

## ニュースレター

- **CTA文言**: 「購入はこちら」「有料noteを読む」はNG。「無料で読む」「今すぐ確認する」「ダウンロードする」などハードルを下げる表現を使う。
- **件名**: 【具体的ベネフィット】を冒頭15文字に。全体50文字以内。数値・期限を入れる。

## コード・変更

- **変更範囲**: タスクに直接必要な変更のみ。 speculative なリファクタや「ついでに」修正はしない（Senior Engineer Task Execution Rule に準拠）。
