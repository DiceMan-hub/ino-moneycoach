マレーシア生活をめちゃくちゃ助けてくれるアプリとサイトです。
いろんなアプリが便利に用意されていて、ほとんどがオンラインで解決します👇 #マレーシア #移住Tips
サイトリンクはリプに。
ほかに便利なアプリやサイトがあったら教えてください‼️🙇

🟠WhatsApp
日本でいうLINE。個人も法人も、法人担当者もみんなWhatsAppで連絡してきます。通話もできます。
マレーシアだけでなく、アジア圏はみんなこれ。昔送った画像やファイルも消えてません。

🟠配車アプリ
Grab / AirAsiaMOVE / inDrive
とにかく安いマレーシアのライドシェア。ほぼほぼGrabですが、料金が高いときや深夜早朝すぎるときなどサービス比較して他社アプリも使います。
AirAsiaMOVEは航空券のチェックインもできます。 安全性はGrabが一段上。
🟠支払いアプリ 各銀行アプリ / Grab / Touch'nGO（略称TNG）

各銀行アプリにはQRコード決済のDuitNowが搭載されてて、だいたいこれ。超シンプルな銀行送金。手数料無料。
Grabで支払うと割引がつくときもあります。ポイントも貯まります。Grabは配車アプリと同じアプリです。
Touch'nGOは日本でいうSuica/Pasmo/ICOCAです。スマホからチャージ可能。
🟠Lazada / Shopee

日本でいうAmazon。質がよい商品も品質が虚偽な商品も混ざってます。でも返品もものすごく簡単。だいたい月イチでセールやってるのでそのときにまとめ買いするとかなり安くなります。日本からの輸入品も出品されてます。
🟠Transit / Moovit

路線アプリ。マレーシアだけでなく、日本含むアジア、ヨーロッパ、南北アメリカ、オーストラリアの路線もこのアプリ一つで調べられる。
路線バスに乗る人はMoovit が正確。
🟠MyTNB

電気代の確認・支払い。これがないと、いつの間にか電気が止められる恐怖と戦うことになります。
🟠MyJPJ  車を運転する人は必須。2026年2月からロードタックス（自動車税）のステッカーが完全に廃止されました。警察の検問でもこのアプリでデジタル免許証と納税証明を見せる必要があります。
🟠Wise
銀行送金との比較で100万円〜125万円程度はWiseのほうが手軽で速いし手数料が安い。高額になる場合はIBKRが有利。
🟠IBKR（Interactive Brokers)
シンガポールまたはオーストラリアの証券取引所。高額の両替でも手数料が固定で超絶安い。

🟠在マレーシア 日本大使館（サイト）
パスポート、マイナンバー、出生届、戸籍の翻訳、在外選挙投票等、区役所っぽいのはぜんぶここ。要予約。

🟠オンライン在留届（サイト）
緊急時の安否確認・支援/領事サービスの円滑化/最新の安全情報の提供/非居住者の根拠など。逆に言うと、海外に3か月以上滞在する日本人は法律で提出が義務づけられています。

🟠両替所のレート確認サイト（サイト）
両替所も日によってJPY-MYRの両替レートが違うので、移住したての頃、どこが有利かよく調べてました。

🟠遺言 AMANAHRAYA（サイト）
公証役場みたいなところ。マレーシアの金融機関に置いてある資産は、亡くなると遺族が裁判所で手続きしないと取り出せなくなります。遺言があるとスムーズに取り出せます。

🟠マレーシア掲示板（サイト）
日本人の情報交換サイト。例えるなら治安の良いジモティー。サイトの歴史も古い。私の周りでも利用者多いです。自己責任で。
