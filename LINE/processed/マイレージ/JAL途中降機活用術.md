# JAL途中降機活用術

## 概要
JALマイルを使った特典航空券では、途中降機を活用することで面白い旅程を組むことができます。

## JMB提携航空会社特典航空券

### 特徴
- ワンワールド以外の航空会社を使いたい時に便利
- **途中降機**: 旅程全体で最大3回まで可能
  - 24時間以上の1都市滞在または地上移動区間
  - 注意: 中国東方航空の中国発国際区間を含む旅程では中国での途中降機は不可

### 活用例：エミレーツ航空
ビジネスクラスやファーストクラスが豪華で有名なエミレーツ航空での発券例：

```
日本 → ドバイ(数日) → マレ(数日) → コロンボ
```

## ワンワールド特典航空券

### 特徴
- 地上移動区間を除き1特典で**8区間まで利用**可能
- JAL Webサイトでの指定：出発地と目的地の組み合わせは6つまで
  - 経由地の指定はできません
- **日本国内区間**: 旅程全体で2区間まで
- **途中降機**: 旅程全体で7回まで可能
  - 24時間以上の1都市滞在または地上移動区間
  - 注意: 日本発着の旅程では日本国内の途中降機は不可

### 活用例：片道世界一周券
様々な航空会社を混ぜて使える多彩な組み合わせ：

```
日本 → アジア(途中降機) ～ 別切りで帰国
別切りで アジア → 欧州(数日) → 北アフリカ(数日) → 北米(数日) → ハワイ(途中降機) ～ 別切りで帰国
別切りで ハワイ → 日本
```

## ポイント
- 途中降機を活用することで、1回の特典航空券で複数都市を楽しめる
- 別切り発券と組み合わせることで、さらに柔軟な旅程が可能
- ワンワールド特典航空券は特に自由度が高く、世界一周旅行にも対応
