私はGitHubでPM Skills Marketplaceを立ち上げました。 65のPMスキルと、8つのClaudeプラグインにわたる36の連鎖ワークフローを、証明されたフレームワークに基づいて提供します。これはオープンソースで、誰でも利用可能です。
Claude CodeとCowork向けに設計されています。スキルは他のAIアシスタントとも互換性があります。 —————
	1	PM Skills Marketplaceの理由は？ 一般的なAIはテキストを提供しますが、PM Skills Marketplaceは構造を提供します。 各スキルは、証明されたPMフレームワーク（発見、仮定マッピング、優先順位付け、戦略など）をエンコードし、ステップバイステップでガイドします。Teresa Torres、Marty Cagan、Alberto Savoiaの厳密さを日常のワークフローに組み込み、本棚に置いておくだけではありません。 結果：より良い製品決定、より速いドキュメント作成だけではない。 —————
	2	仕組み（スキル、コマンド、プラグイン） スキルはマーケットプレイスのビルディングブロックです。各スキルは、特定のPMタスクに対してドメイン知識、分析フレームワーク、またはガイド付きワークフローをClaudeに提供します。一部のスキルは、複数のコマンドで共有される再利用可能な基盤としても機能します。 スキルは会話に関連する場合に自動的にロードされます—明示的な呼び出しは必要ありません。必要に応じて（例：一般知識よりスキルを優先する場合）、/plugin-name:skill-name または /skill-name で強制的にロードできます（Claudeがプレフィックスを追加します）。 コマンドはユーザーによってトリガーされるワークフローで、/command-name で呼び出されます。これらは1つ以上のスキルを連鎖させてエンドツーエンドのプロセスを作成します。例えば、/discover は4つのスキルを連鎖：brainstorm-ideas → identify-assumptions → prioritize-assumptions → brainstorm-experiments。 プラグインは関連するスキルとコマンドをインストール可能なパッケージにグループ化します。各プラグインはPMドメイン（発見、戦略、実行など）をカバーします。マーケットプレイスをインストールすると、8つのプラグインがすべて一度に取得されます。
コマンドはスキルを使用します。一部のスキルは複数のコマンドに役立ちます。一部のスキル（例：prioritization-frameworks または opportunity-solution-tree）はスタンドアロンの参照で、Claudeが関連する場合にいつでも引き出されます—コマンドは必要ありません。
コマンドはPMワークフローに合わせて互いに流れるように設計されています。任意のコマンドが完了すると、関連する次のコマンドを提案します—プロンプトに従ってください。 このプロジェクトが役立つ場合、GitHubのリポジトリに⭐をつけてください。 ————— 3. インストール 3.1 Claude Cowork（非開発者向け） Customize（左下）を開く Browse plugins → Personal → + を選択 Add marketplace from GitHub を選択 入力：phuryn/pm-skills 8つのプラグインがすべて自動的にインストールされます。コマンド（/discover、/strategy など）とスキルを取得します。 3.2 Claude Code（CLI）
3.3 他のAIアシスタント（スキル限定） skills/*/SKILL.md ファイルはユニバーサルスキルフォーマットに従い、それを読み取る任意のツールで動作します。コマンド（/slash-commands）はClaude専用です。
