税務より苦労した！！

労務MCPサーバー「labor-law-mcp」を公開しました。

Claudeが労務の質問に答えるとき、条文や通達のハルシネーションを防ぐためのMCPサーバーです。

■ 何ができるか

Claudeに労務の質問をすると、回答の裏取りとして以下の原文を自動取得します:

・e-Gov法令API → 労働基準法、雇用保険法、健康保険法など45法令の条文

・厚労省法令等データベース → 厚労省通達（36協定、パワハラ防止指針の運用通達など）

・安全衛生情報センター（JAISH） → 安衛法関連の通達

全6ツール搭載:
get_law / search_law / search_mhlw_tsutatsu / get_mhlw_tsutatsu / search_jaish_tsutatsu / get_jaish_tsutatsu

■ 経緯

先に税法版のMCPサーバー（tax-law-mcp）を作っていたので、そのアーキテクチャをそのまま応用して作りました。

ただ、「労務」は税法と比べて範囲が広すぎて難しかったです。
税法はe-Gov法令APIと国税庁の通達・裁決事例でほぼカバーできますが、労務は厚労省の通達DB、安全衛生情報センターなど、データソースが分散しています。

さらに、パワハラ防止指針のような告示PDFはどのAPIからも取れないケースがある。

そこで、MCPサーバーで取得した原文を「一次情報」、WebSearchで補完した情報を「二次情報」と明確に区分して表示する仕組みを入れました。
二次情報には情報源と信頼度（政府系サイト→高 / 法律事務所の解説→中 / 個人ブログ→低）を付記させています。AIが「取れなかった」ことをごまかさず、ユーザーが情報の確度を判断できるようにしています。
これでclaudeと喧嘩しませんね。

これらの経験はtax-law-mcpにもフィードバックしたので、税法版のMCPも一緒に洗練されました。
作る順番がtax→laborだったからこそ得られた改善です。

■ 誰向け？

当然、社労士さん向けですが、会計事務所の方も参考にお使いいただくと便利かなと思います。
あくまで参考ですが。

■ 対応法令（45法令）

労働基準法、労働契約法、最低賃金法、労働安全衛生法、雇用保険法、労災保険法、労働者派遣法、職業安定法、健康保険法、厚生年金保険法、国民年金法、介護保険法、育児介護休業法、男女雇用機会均等法、パートタイム・有期雇用労働法、労働施策総合推進法（パワハラ防止法）、社会保険労務士法、その他各施行令・施行規則

「労基法」「安衛法」「育介法」「健保法」等の略称にも対応。

■ セットアップ（コピペ1行）

Claude Codeの場合:
claude mcp add labor-law -- npx -y labor-law-mcp

Claude Desktopの場合:
設定ファイルに以下を追加:

{
  "mcpServers": {
    "labor-law": {
      "command": "npx",
      "args": ["-y", "labor-law-mcp"]
    }
  }
}
