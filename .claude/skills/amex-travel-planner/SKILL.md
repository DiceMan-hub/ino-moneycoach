# Amex トラベルプランナー スキル

アメックスのFHR（Fine Hotels & Resorts）とTHC（The Hotel Collection）の料金をスクレイピングし、特定の旅行期間内で最安値かつ移動距離最小の組み合わせプランを策定してエクセルで出力します。

---

## 前提知識

### FHR（Fine Hotels & Resorts）
- アメックスプラチナ/センチュリオンカード特典
- **滞在ルール**: 旅行期間中、FHRへのチェックアウトは**最大2回**まで
- **最低滞在**: 通常1泊から利用可能
- **付帯特典**: 無料朝食2名分、客室アップグレード、アーリーチェックイン/レイトチェックアウト、施設クレジット（$100〜$150）等
- **限定オファー例**: 3泊目無料、4泊目無料、15%オフ等

### THC（The Hotel Collection）
- **滞在ルール**: 旅行期間中、THCへのチェックアウトは**最大2回**まで
- **最低滞在**: **2泊以上**必須
- **付帯特典**: ホテルクレジット（$100）等
- **限定オファー例**: 3泊目無料、特定期間割引等

### 対象チェーン優先順位（ポイント・会員特典との併用）
1. **Marriott Bonvoy チタン**: Marriott/SPG/Westin/Sheraton/W等 → ポイント積算・スイートアップグレード等
2. **IHG ダイヤモンド + アンバサダー**: IHG/InterContinental/Kimpton/Crowne Plaza等 → ラウンジアクセス・ポイント等
3. **Hyatt グローバリスト**: Park Hyatt/Grand Hyatt/Andaz等 → スイートアップグレード・ポイント等
4. **Hilton ゴールド**: Hilton/Waldorf Astoria/Conrad等 → 朝食・ポイント等

## ワークフロー概要

```
Step 1: 対象期間と旅先の確認
Step 2: maxfhr.comで料金スクレイピング
Step 3: 限定オファーの確認と追記
Step 4: Googleでホテル住所を検索・追記
Step 5: 最安値+最適移動距離のプラン策定
Step 6: エクセル出力
```

## Step 1: 情報収集（ユーザーへの確認）

スキル開始時に以下を確認する（未提供の場合のみ質問）:

- **目的地（都市/地域）**: 例「東京」「パリ」「ニューヨーク」
- **旅行期間**: 例「2025年3月1日〜15日の中で選択」
- **総泊数の目安**: 例「合計7泊」
- **優先チェーン**: 未指定なら上記優先順位を適用
- **予算感（任意）**: 1泊あたりの上限（任意）

---

## Step 2: maxfhr.comで料金スクレイピング

### 2a. サイトへのアクセス
```
Navigate to: https://www.maxfhr.com
```

### 2b. 検索パラメータの設定

1. ブラウザでmaxfhr.comを開く
2. 目的地を入力（英語推奨）
3. チェックイン日・チェックアウト日を設定
4. 「FHR」「THC」のフィルターを確認
5. 複数日程を繰り返し検索（期間内の全日程）

### 2c. スクレイピングのポイント

- **料金表示**: 1泊あたりの料金（税込/税別を確認）
- **ホテル名**: 正式名称を記録
- **カテゴリ**: FHR or THC
- **チェーン判別**: ホテル名からMarriott/IHG/Hyatt/Hilton/その他を判別
- **特記事項**: 「Offer」「3rd Night Free」等の表示を確認

### 2d. 料金リスト作成

以下の形式でデータを蓄積:
```
ホテル名 | カテゴリ | チェーン | チェックイン | チェックアウト | 泊数 | 1泊料金 | 合計料金 | 特別オファー | 住所（後で追記）
```

---

## Step 3: 限定オファーの確認と追記

### 3a. maxfhr.comのオファーページを確認
- サイト内の「Special Offers」「Promotions」等を確認
- FHR/THCの期間限定オファーをリストアップ

### 3b. アメックストラベルサイトでの確認
```
Navigate to: https://travel.americanexpress.com
```
- Fine Hotels + Resorts のセクションへ移動
- 対象ホテルの特別オファーを確認

### 3c. オファーの種類と計算方法

| オファータイプ | 計算方法 |
|--------------|----------|
| 3泊目無料 | (1泊料金 × 2) ÷ 3泊 = 実質1泊単価 |
| 4泊目無料 | (1泊料金 × 3) ÷ 4泊 = 実質1泊単価 |
| 15%オフ | 1泊料金 × 0.85 = 実質単価 |
| 特定日無料 | 対象日の料金を差し引き |

- リストの「特別オファー」列に記載
- 「実質単価（オファー適用後）」列を追加して再計算

---

## Step 4: Googleでホテル住所を検索

### 4a. 各ホテルのアドレス取得

ウェブ検索ツールを使用:
```
検索クエリ: "{ホテル名} address {都市名}"
```

または:
```
検索クエリ: "{ホテル名} {都市名} 住所"
```

### 4b. 住所の記録形式
- 英語住所（緯度経度があれば尚可）
- 「エリア/地区名」も記録（例: Midtown, 7th Arrondissement）

### 4c. Google Mapsでの距離計算
各ホテル間の移動距離・時間を概算:
- 徒歩距離（1km以内）
- タクシー/公共交通時間
- 同エリア内かどうかの判別

---

## Step 5: 最適プランの策定

### 5a. プラン策定の制約条件

1. **FHRルール**: 旅行期間中、FHRチェックアウトは最大2回
2. **THCルール**: 旅行期間中、THCチェックアウトは最大2回、かつ1滞在2泊以上
3. **優先チェーン**: Marriott → IHG → Hyatt → Hilton → その他
4. **移動距離最小化**: 同エリア内のホテル間移動を優先
5. **コスト最小化**: 実質単価（オファー適用後）で比較

### 5b. 最適化アルゴリズム（手順）

```
1. 全ホテルを「エリア/地区」でグループ化
2. 各エリアの最安FHR・最安THCを特定
3. 優先チェーンのホテルにボーナスポイントを付与してスコアリング
4. 2回のFHRチェックアウト + 2回のTHCチェックアウト（各2泊以上）の組み合わせを列挙
5. 各組み合わせの総コストを計算（オファー適用後）
6. 移動距離スコアを加算（同エリア滞在 = ボーナス）
7. 総合スコアで上位3プランを選出
8. 最優秀プランを「推奨プラン」として採用
```

### 5c. スコアリング基準

| 項目 | 重み |
|------|------|
| 総コスト（低いほど高得点） | 50% |
| 優先チェーン一致 | 20% |
| 移動距離（短いほど高得点） | 20% |
| 特典価値（オファー・付帯特典） | 10% |

### 5d. プランの構成要素

推奨プランには以下を含める:
- 滞在ホテル名・カテゴリ（FHR/THC）
- チェックイン/アウト日
- 泊数
- 1泊単価（オファー適用後）
- 合計コスト
- 付帯特典の価値概算
- 移動ルート（A→B→C の形式）

## エラーハンドリング・注意事項

### maxfhr.comへのアクセス
- アクセスができない場合: Googleでホテル検索し、アメックストラベルサイトで料金確認
- 料金が表示されない場合: 日程をずらして再検索

### 料金の通貨
- デフォルト: USD表示
- 必要に応じてJPY換算（ユーザーの希望に応じて）

### ホテルの営業状況
- 検索結果に「Closed」「Not Available」の場合はリストから除外
- 季節営業ホテルに注意

### 特別オファーの条件
- 最小泊数条件を確認（「3泊目無料」は3泊必要）
- 予約窓口の条件（アメックストラベル経由のみ等）を記載

### 会員資格の適用
- FHR/THC経由の予約でもMarriott/IHG/Hyatt/Hiltonのポイントが付く場合があるため、ホテルのフロントで確認を推奨
- IHGアンバサダーのラウンジアクセス権は、ホテルにラウンジがある場合のみ有効
