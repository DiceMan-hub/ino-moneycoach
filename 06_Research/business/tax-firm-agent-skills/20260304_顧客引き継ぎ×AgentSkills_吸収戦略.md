# リタイア税理士からの顧客引き継ぎ × Agent Skills 戦略

> **作成日**: 2026-03-04（03-04 全顧客引き受け制約を反映して改訂）
> **前提**:
> - 自社: 社長＋5人の税理士事務所（税務・会計・M&A・経営成長支援）
> - 引き継ぎ元: リタイアする税理士の事務所
> - **制約: 最初の1年は全顧客を引き受ける約束**
> - 顧客の質: まばら（良い顧客〜微妙な顧客が混在）
> - 目的: この吸収を「単なる引き継ぎ」ではなく「事業の飛躍点」にする

---

## 0. 「全部引き受ける」制約の捉え方

### これは制約ではなく、武器にできる

```
「全部受ける」のネガティブな解釈:
  → 微妙な顧客も断れない → 工数圧迫 → 地獄の1年

「全部受ける」のポジティブな解釈:
  → 1年間の「有料トライアル」を全社に提供する権利を得た
  → 12ヶ月分のリアルデータが手に入る（机上の評価より正確）
  → 1年後に「実績ベース」で顧客を選べる（感情的に断るより圧倒的に楽）
  → 前税理士への義理も果たせる → 業界内の評判UP
```

### 戦略の基本方程式

```
全員受ける ≠ 全員を同じに扱う

全員受ける = スコアリング → ティア分け → リソース傾斜配分
            + 1年後の「卒業」設計を初日から仕込む
```

---

## 1. 引き継ぎの本質的な問題

### よくある失敗パターン（全顧客引き受け時に最も危険）

```
全顧客を同じサービスレベルで受ける
→ 微妙な顧客が工数を食う（安い顧問料で要求だけ多い）
→ 良い顧客へのサービスが薄くなる
→ 良い顧客から「前の先生の方がよかった」と言われる
→ 最悪、良い顧客が離脱して微妙な顧客だけ残る
→ 1年後、全員残ったが利益率は壊滅
```

### 本当にやるべきこと

```
全員受ける + ティア別のサービス設計 + 1年後の出口設計
= 「1年間の有料市場調査」として最大限のデータを取りながら
  良い顧客にはファンになってもらい、
  微妙な顧客には自然に離れてもらう仕組みを作る
```

**引き継ぎは「顧問契約をゼロからやり直す」唯一の機会。**
全員受けても、条件は全員リセットできる。これが最大のレバレッジ。

## 2. 引き継ぎの4フェーズ設計

```
Phase A: 分類＋準備（引き継ぎ前）
  ↓
Phase B: リセット＋初回インパクト（引き継ぎ直後〜3ヶ月）
  ↓
Phase C: 観察＋アップグレード（3ヶ月〜9ヶ月）
  ↓
Phase D: 1年レビュー＋再編（10〜12ヶ月）← ★ここが出口
```

## Phase A: 分類＋準備（引き継ぎ前 — 全員受ける前提でやること）

### A-1. 顧客データの一括アセスメント

**Agent Skill: `/client-assessment`**

リタイア税理士から受け取るデータ:
- 顧問先リスト（社名、業種、売上規模、従業員数）
- 現在の顧問料・報酬体系
- 過去の申告書（直近3年）
- 月次の作業ボリューム（記帳代行の有無、仕訳数）
- 特記事項（トラブル履歴、要注意事項）

Agentに投入して自動スコアリング:

```
スコアリング項目（各10点、合計100点）:

1. 売上規模（事務所にとっての成長余地）
   - 年商1億以上=10, 5000万=7, 1000万=4, 500万以下=2

2. 顧問料の妥当性（工数に対して適正か）
   - 月10万以上=10, 5-10万=7, 3-5万=5, 3万未満=2

3. 業種の親和性（自事務所の得意分野か）
   - 得意業種=10, 普通=5, 不慣れ=2

4. 記帳代行の有無（工数が重いか）
   - 自計化済み=10, 一部代行=5, 全部代行=2

5. 成長性（売上が伸びているか）
   - 成長中=10, 横ばい=5, 縮小=2

6. M&A・事業承継の可能性
   - 高い=10, あり得る=5, なし=2

7. コミュニケーションの質（前税理士からの評判）
   - 協力的=10, 普通=5, 手がかかる=2

8. 追加サービスの余地（経営支援等を受け入れそうか）
   - 積極的=10, 興味あり=5, 不要=2

9. 紹介可能性（その顧客からの横展開）
   - 高い=10, 可能性あり=5, 低い=2

10. リスク（税務調査リスク、トラブル履歴）
    - 低い=10, 普通=5, 高い=2
```

### A-2. 全顧客を4ティアに分類（全員受けるが、対応を変える）

| ティア | スコア | 初年度の方針 | リソース配分 | 1年後の見通し |
|--------|--------|------------|------------|-------------|
| **S: 戦略顧客** | 80+ | 社長直轄。最高のサービスで「この事務所すごい」を実感させる | **手厚い** | 長期パートナーへ |
| **A: 育成顧客** | 60-79 | 提案型サービスで信頼構築。価格改定も受け入れやすい層 | **標準+α** | 顧問料UP＋紹介元に |
| **B: 効率化顧客** | 40-59 | Agentで自動化。人手をかけない仕組みで回す | **最小限** | 条件次第で継続 |
| **C: 観察顧客** | 39以下 | 最低限のサービス。工数を計測して「赤字か黒字か」を見る | **極小** | 1年後に卒業候補 |

**ポイント: 断らない。ただし、ティアごとにサービス内容と顧問料を変える。**

### A-3. ティア別の初年度サービス設計

| サービス内容 | S | A | B | C |
|------------|---|---|---|---|
| 月次面談 | ◎ 毎月 | ○ 隔月 | △ 四半期 | × 必要時のみ |
| 税務ヘルスチェック | ◎ 詳細版 | ○ 標準版 | △ 簡易版 | △ 簡易版 |
| 節税提案 | ◎ 個別設計 | ○ 標準提案 | △ 汎用レポート | × なし |
| KPIレポート | ◎ | ○ | × | × |
| 経営相談 | ◎ 随時 | ○ 予約制 | × | × |
| 記帳代行 | 要望に応じて | 要望に応じて | 自計化を推進 | 自計化が条件 |
| 担当者 | 社長 or シニア | シニア | ジュニア+Agent | Agent主導 |

### A-4. 顧問料の再設計（全社リセット）

**全員受ける＝全員の契約を新規で結ぶ。旧事務所の価格に縛られる必要はない。**

```
前税理士の事務所: 月2万で20年。値上げなし。記帳も申告も含む。
                → 顧客は「月2万が普通」と思っている

新事務所の契約:
  「前事務所の顧問料をベースに、サービス内容に応じた新料金をご案内します」

ティア別の価格設計:
  S: 月10-15万（経営支援込み。前事務所の3-5倍でも価値で納得）
  A: 月5-8万（提案型。前事務所の2-3倍だがヘルスチェックで根拠を示す）
  B: 月3-5万（標準的。前事務所と同等 or やや増）
  C: 月3万〜（最低ライン。これ以下なら赤字と明示）
```

**全社に同じ手紙/メールを送るのではなく、ティア別に面談のトーンを変える。**

### A-5. 「全顧客引き受け」を前税理士に伝えるときの条件設定

前税理士に「全部受けます」と約束する代わりに、以下を取り付ける:

```
□ 全顧客を引き受けるが、顧問料・サービス内容は新事務所の基準で再契約する
  （旧料金をそのまま引き継ぐ約束はしない）
□ 前税理士が顧客に「新しい事務所の方針に従ってください」と一言添える
□ 引き継ぎ後3ヶ月は前税理士に質問できる窓口を残す
□ 1年後の契約更新は双方合意（自動更新ではない）
□ 引き継ぎ顧客からの紹介が発生した場合のルール（紹介料 or なし）
```

**最も重要なのは1番目。「全部受けるが、価格は変える」を事前に合意しておく。**

## Phase B: リセット（引き継ぎ直後〜3ヶ月）

### B-1. 初回面談で全顧客に「税務ヘルスチェック」を実施

**Agent Skill: `/tax-diagnostic`（前回作成済み）**

**これが引き継ぎ戦略の核心。**

```
リタイア税理士の顧客が不安に思っていること:
  「新しい先生、大丈夫かな？」
  「前の先生と同じことやってくれるのかな？」
  「余計な費用を取られないかな？」

税務ヘルスチェックが解決すること:
  「前の事務所では見つけてもらえなかった節税策を提案してくれた」
  「この事務所、ちゃんと見てくれている」
  「変えてよかった」←★ この感情を初回で作る
```

**具体的なフロー:**

```
1. 引き継ぎ挨拶の面談を設定（全顧客に）

2. 面談前にAgentで準備（所要時間: 15-30分/社）
   - 過去3年の申告書データを投入
   - /tax-diagnostic を実行
   - 「御社の税務ヘルスチェックレポート」を生成
   - 控除の漏れ、経費の改善余地、法人化の検討等を自動検出

3. 面談（30-60分）
   - 「事務所の引き継ぎにあたり、まず御社の税務状況を
      改めて見直させていただきました」
   - ヘルスチェックレポートを渡す（←これが感動ポイント）
   - 「前の先生では〇〇が未活用でした。これだけで年間XX万円の節税になります」
   - 新しい顧問契約の条件を提示

4. 面談後のフォロー
   - 提案した施策の実行サポート
   - 「引き継いでよかった」の実感を早期に作る
```

**Agentがないと**: 100社の引き継ぎで全部に丁寧な初回面談は不可能。形式的な挨拶で終わる。
**Agentがあると**: 全社にヘルスチェックレポートを配れる。準備は15分/社で済む。

### B-2. 顧問契約のリセット

引き継ぎ = 契約条件を見直す自然な機会

| 項目 | 前事務所 | 新条件 |
|------|---------|--------|
| 顧問料 | 月2万で20年据え置き | 適正価格に改定（月3-5万） |
| サービス内容 | 記帳＋申告のみ | 記帳＋申告＋税務診断＋節税提案 |
| 面談頻度 | 年1回（申告時のみ） | 四半期レビュー |
| 報告内容 | 申告書の控えだけ | KPIレポート＋節税レポート |

**値上げの根拠が「税務ヘルスチェック」で示された節税額。**
「年間30万円の節税を見つけました。顧問料は月3万→5万になりますが、差額の月2万を大幅に上回る節税効果があります」

### B-3. 業務の標準化

**Agent Skill: `/onboarding-checklist`**

引き継ぎ顧客ごとに自動生成:

```
□ 基本情報の登録（会計ソフトへの登録）
□ 過去3年の申告書の確認・保管
□ 現在の記帳方法の確認（自計化 / 代行）
□ 通帳・クレカ明細の連携設定
□ 届出書の確認（青色申告、消費税、インボイス等）
□ 決算期・申告期限の確認
□ 前事務所との引き継ぎ事項の確認
□ 初回面談の実施・ヘルスチェックレポートの配布
□ 新顧問契約の締結
□ 月次巡回のスケジュール設定
```

5人で100社を引き継ぐなら、**1人あたり20社。漏れが出る。**
チェックリストの自動生成＋進捗管理がないと破綻する。

## Phase C: アップグレード（3ヶ月〜12ヶ月）

### C-1. 引き継ぎ顧客のランクアップ戦略

| ランク | 3ヶ月後のアクション |
|--------|-------------------|
| **S顧客** | 経営支援プラン（月10万〜）を提案。社長が直接担当。M&A・事業承継の相談を開始 |
| **A顧客** | 四半期レビュー開始。KPIレポートを提供。ふるさと納税・節税提案を定期実施 |
| **B顧客** | 顧問料改定の実施。自計化を促進（記帳代行の工数削減）。改善なければ最低プランに |
| **C顧客**（引き受けた場合） | 最低限のサービスに限定。1年後に契約更新判断 |

### C-2. クロスセル・アップセルのAgent

**Agent Skill: `/upsell-detector`**

月次データを見て、追加サービスの機会を自動検出:

```
検出パターン例:

- 売上が急成長中 → 「法人化の相談、そろそろいかがですか？」
- 役員が高齢 → 「事業承継の準備を始めませんか？」
- 借入金が多い → 「資金繰り改善のご提案があります」
- 個人事業主で所得500万超 → 「法人化で年間XX万円の節税が可能です」
- 不動産を保有 → 「相続税対策のご提案があります」
- 従業員が増加 → 「就業規則・社労士の紹介も可能です」
- 海外取引が発生 → 「国際税務のサポートを始めましょう」
```

**前の税理士が「聞かれたことだけ答える」スタイルだった場合、これだけで劇的な差別化になる。**

### C-3. 引き継ぎ顧客からの紹介獲得

```
初回面談で感動を与える
→ 「新しい税理士に変えてよかった」
→ 「うちもいい税理士探してるんだけど」と紹介が生まれる

引き継ぎ50社のうち10社が1社ずつ紹介 = +10社
紹介顧客は初めから信頼がある = 成約率が高い
```

**Agent Skill: `/referral-program`**
- 引き継ぎ3ヶ月後に全顧客にアンケート送付（満足度調査 ＋ 紹介の依頼）
- 高満足度の顧客に紹介カードを送付
- 紹介成約時のインセンティブ設計（顧問料1ヶ月無料等）

## 3. Agentなしとありの比較

### 50社引き継ぎの場合

| 項目 | Agentなし | Agentあり |
|------|----------|----------|
| 引き継ぎ前の顧客評価 | 社長の勘と前税理士の口頭説明 | **全社スコアリング。データで判断** |
| 初回面談の準備 | 申告書をざっと読む（1社1時間） | **ヘルスチェック自動生成（1社15分）** |
| 初回面談の質 | 挨拶＋「何かお困りのことは？」 | **レポート渡して節税額を提示。感動** |
| 顧問料の改定 | 「値上げさせてください」（根拠弱い） | **「年間XX万円の節税を見つけました」（根拠強い）** |
| 全体の工数 | 50社 × 3時間 = 150時間 | **50社 × 1時間 = 50時間** |
| 3ヶ月後の状態 | やっと全社の顔を覚えた | **S/A顧客にアップセル開始** |
| 1年後の増収 | 顧問料合計が少し増えた程度 | **顧問料UP＋アップセル＋紹介で大幅増収** |

### 数字のインパクト

```
50社引き継ぎの場合:

Agentなし:
  50社 × 平均月3万 = 月150万の売上増
  工数増: 職員1人分（年間500万のコスト）
  実質利益: 月150万 - 月42万（人件費） = 月108万

Agentあり:
  50社 × 平均月5万（値上げ後） = 月250万の売上増
  追加工数: 職員0.5人分（Agentで効率化）
  アップセル: 10社 × 月3万追加 = 月30万
  紹介獲得: 10社 × 月5万 = 月50万（半年後から）
  実質利益: 月330万 - 月21万（人件費） = 月309万

差額: 月201万 = 年間2,412万
```

## 5. 社長が判断すべきこと（Agentでは代替できない）

| 判断事項 | なぜ社長が必要か |
|---------|----------------|
| C顧客を断る基準の最終決定 | 事務所の方針と前税理士との関係性の判断 |
| S顧客への初回面談 | 信頼関係は人がつくる。社長の顔を見せる |
| 顧問料の最終価格 | 市場感覚と交渉は人の仕事 |
| 前税理士との引き継ぎ条件交渉 | 紹介料・引き継ぎ期間・データ移管の取り決め |
| 職員のアサイン | 誰がどの顧客を担当するかの最適配置 |

**Agentは「情報を整理して選択肢を提示する」。最終判断は社長がやる。**

## 7. 前税理士から引き出すべき情報（チェックリスト）

Agentの精度を上げるために、引き継ぎ前にこれだけは確保する:

```
□ 顧問先一覧（社名、代表者、業種、設立年、決算月）
□ 各社の顧問料・報酬体系（月額 / 決算料 / 年調 等）
□ 過去3年の申告書（法人税 / 所得税 / 消費税）
□ 記帳代行の有無、月間仕訳数の目安
□ 使用会計ソフト（弥生 / freee / マネフォ / TKC / その他）
□ 特記事項（税務調査履歴、トラブル、性格的な注意点）
□ 顧問先の関心事（節税、融資、事業承継、M&A等）
□ 前税理士の担当者（誰がメインで対応していたか）
□ コミュニケーション方法（対面 / 電話 / メール / LINE）
□ 未処理案件・懸案事項
```

**「性格的な注意点」は最も重要。数字に出ないが工数を左右する。**

## Phase D: 1年レビュー＋再編（10〜12ヶ月目）★全顧客引き受け時の出口設計

### D-1. なぜ10ヶ月目から始めるか

```
12ヶ月目に突然「来月から契約変更です」は関係が壊れる。
10ヶ月目に全社レビュー → 11ヶ月目に面談 → 12ヶ月目に新契約 or 卒業
```

### D-2. 全顧客の「1年間実績レポート」を自動生成

**Agent Skill: `/annual-client-review`**

1年間で蓄積したデータから、顧客別にレポートを自動生成:

```
レポートの内容:
  ■ 定量データ
  - 年間の顧問料収入
  - 実際にかかった工数（時間）
  - 時間単価（顧問料 ÷ 工数）← 事務所内部用。顧客には見せない
  - 追加サービスの利用状況
  - コミュニケーション頻度（電話・メール・面談の回数）

  ■ 定性データ
  - 顧客の協力度（資料提出の遅延回数、レスポンス速度）
  - 追加提案への反応（受け入れた / 無関心 / 拒否）
  - クレーム・トラブルの有無
  - 紹介の実績

  ■ 判定
  - 時間単価ランク: A（5,000円/h以上） B（3,000-5,000円） C（3,000円未満） D（赤字）
  - 成長性ランク: ↑（売上増加中）→（横ばい）↓（縮小中）
  - 総合判定: 継続推奨 / 条件見直し / 卒業候補
```

**初日のスコアリング（机上評価）と、12ヶ月の実績データを突合する。**
「予想通り良い顧客」「予想より良かった顧客」「予想より悪かった顧客」が明確になる。

### D-3. 1年後の4つの出口

| 判定 | 対象 | アクション | 伝え方 |
|------|------|----------|--------|
| **継続＋拡大** | S・A顧客 | 2年目以降の経営支援プランを提案。顧問料UP | 「1年間ありがとうございました。2年目はさらに踏み込んだ支援をご提案します」 |
| **継続＋現状維持** | B顧客（採算OK） | 現条件で継続。自計化がさらに進めば利益率UP | 「引き続きよろしくお願いします」 |
| **条件見直し** | B顧客（採算NG） | 顧問料UP or サービス縮小 | 「1年間の実績を踏まえ、サービス内容と料金を見直させてください」 |
| **卒業（移管）** | C顧客（赤字・高負荷） | 他事務所を紹介して移管 | 下記参照 |

### D-4. C顧客の「卒業」の伝え方

**絶対にやってはいけない**: 「うちでは対応しきれません」（= 能力不足に聞こえる）

**正しい伝え方のパターン:**

```
パターン1: 専門性のミスマッチ
「1年間担当させていただき、御社の事業は〇〇の専門知識が必要だと
 わかりました。その分野に強い事務所をご紹介した方が、
 御社にとって良い結果につながると思います」

パターン2: サービスレベルの不一致
「弊所は来期から経営支援を強化する方針です。
 御社が求めておられる記帳中心のサービスは、
 〇〇事務所の方がコスト面でも適しています」

パターン3: 価格改定に伴う自然離脱
「2年目からサービス内容を拡充し、顧問料を月〇万円に
 改定させていただきます。もし他の選択肢をご検討される場合は、
 信頼できる事務所をご紹介いたします」
 → 価格が上がれば、C顧客の一部は自分から離脱する
```

**パターン3が最も自然で摩擦が少ない。**
「値上げします → 合わないなら紹介します」は、断っているのではなく選択肢を提示している。

### D-5. 1年後に自然に「卒業」してもらう仕掛け（初日から仕込む）

**Agent Skill: `/natural-exit-design`**

初日から12ヶ月後を見据えて仕込む仕掛け:

```
仕掛け1: 1年契約を明示する
  「まずは1年間、お互いの相性を確認する期間とさせてください」
  → 12ヶ月後の見直しが「当然のこと」になる

仕掛け2: サービス内容を明文化する
  「月額〇万円に含まれるサービスは以下の通りです」
  → 範囲外の要求が来たら「別途お見積りです」と言える根拠

仕掛け3: 工数の可視化
  毎月の作業報告を送る（5分でAgentが自動生成）
  → 顧客自身が「自分がどれだけ手間をかけているか」を認識する
  → 値上げ時の根拠になる

仕掛け4: 自計化の推進（B・C向け）
  「会計ソフト（freee等）の導入をお手伝いします」
  → 自計化すれば事務所の工数が減る
  → 自計化した顧客は「自分でできる」と気づき、安い事務所に移る可能性
  → それはそれで良い（工数が空く）

仕掛け5: 価格表の段階的開示
  引き継ぎ時「初年度は旧料金を参考にご案内します」
  6ヶ月後 「来期からの標準料金表をお送りします」
  10ヶ月後「来期の契約更新のご案内です」
  → 段階的に「値上げ」を予告するので、12ヶ月目にサプライズにならない
```

## 「全員受ける」制約下の工数管理

### 5人で回すための現実的なリソース配分

仮に引き継ぎが50社の場合:

| ティア | 社数 | 担当 | 月間工数/社 | 月間合計工数 |
|--------|------|------|-----------|------------|
| S（10%） | 5社 | 社長 | 8時間 | 40時間 |
| A（35%） | 17社 | シニア2名 | 4時間 | 68時間 |
| B（35%） | 18社 | ジュニア+Agent | 2時間 | 36時間 |
| C（20%） | 10社 | Agent主導+ジュニア確認 | 1時間 | 10時間 |
| **合計** | **50社** | | | **154時間/月** |

```
154時間 ÷ 22営業日 ÷ 5人 = 1人あたり1日1.4時間の追加
```

**Agentなしの場合:**
- B・C顧客にも月3-4時間/社 → 28社 × 3.5時間 = 98時間追加
- 合計: 40+68+98 = 206時間 → 1人あたり1日1.9時間追加
- しかも品質が均一にならない

**Agentありの場合:**
- B・C顧客はAgentが下処理 → 人は確認だけ
- 浮いた52時間/月をS・A顧客の提案活動に投下できる

### 繁忙期（11-3月）の乗り切り方

```
引き継ぎが10月-11月にかかると、繁忙期と重なる最悪のパターン

対策:
1. 引き継ぎの初回面談は10-11月に集中して終わらせる
   （12月以降は通常業務で手一杯）
2. B・C顧客の記帳は繁忙期中もAgentで回す
3. 前税理士に「3月まで質問させてください」を取り付ける
4. 引き継ぎ顧客の申告は前事務所のデータをそのまま使う（初年度は改善より正確さ優先）
```

## 1年間のデータ蓄積が生む「最強の判断材料」

### 机上評価（Day 0）vs 実績データ（Month 12）

| 項目 | Day 0（スコアリング） | Month 12（実績） |
|------|---------------------|-----------------|
| 顧客の質 | 前税理士の主観 + 申告書の数字 | **12ヶ月分の実体験** |
| 工数 | 推定 | **実測値（時間記録）** |
| 収益性 | 概算 | **顧問料÷実工数 = 正確な時間単価** |
| 成長性 | 過去3年のトレンド | **直近12ヶ月の実績** |
| 相性 | 不明 | **明確（担当者の肌感覚 + 対応記録）** |

**1年間全員を見たからこそ、2年目の判断は完璧にできる。**
「よく知らないまま断る」より「1年間見た上で選ぶ」の方が、
前税理士にも顧客にも自分にも説明がつく。

## まとめ：全顧客引き受けを最大の武器にする5原則

```
1. 全員受ける ≠ 全員同じに扱う
   → ティア分けしてリソースを傾斜配分

2. 1年目は「有料の市場調査」
   → 顧問料をもらいながら、全顧客のリアルデータを取得

3. 出口は初日に設計する
   → 1年契約の明示、価格表の段階的開示、自計化推進

4. Agentで下位ティアの工数を圧縮
   → 浮いた時間を上位ティアの感動体験に投下

5. 12ヶ月後、実績ベースで再編
   → 「予想と違った」顧客を正しいティアに再配置
   → 赤字顧客は自然に卒業してもらう
```
