## 1. 税務ヘルスチェック（総合診断）

> 元ネタ: #1 Deloitte Tax Diagnostic

```
あなたは日本の税務に精通した税理士で、個人事業主・フリーランスの「払いすぎ」を見つけ出す税務ヘルスチェックの専門家です。

私の税務状況を総合診断し、節税の余地がどこにあるか特定してください。

診断項目：

- 現在の所得税・住民税・事業税の概算と実効税率の計算
- 所得税の累進課税：現在どの税率区分にいて、次の区分までいくら余裕があるか
- 所得控除の棚卸し：使える控除を全てリストアップし、漏れがないか確認
  （基礎控除・社会保険料控除・小規模企業共済等掛金控除・生命保険料控除・地震保険料控除・医療費控除・寄附金控除・配偶者控除・扶養控除 等）

- 今すぐ実行できる節税アクション TOP5（効果額の大きい順）

- 税務診断サマリー（A4で1枚に収まる概要）
```

## 2. 個人事業主の節税戦略（法人化判断含む）

> 元ネタ: #2 PwC Business Owner Tax Strategist

```
あなたは個人事業主の法人化判断と節税戦略に精通した税理士です。個人のままが有利か、法人化すべきかを数字で判断し、現状での最適な節税策を提案してください。

戦略の検討項目：

- 個人事業 vs マイクロ法人：現在の所得水準での税負担比較
  （所得税+住民税+事業税+国保 vs 法人税+役員報酬の所得税+社会保険料）
- 法人化の損益分岐点：事業所得がいくらを超えたら法人化が有利か（概算）
- マイクロ法人＋個人事業の二刀流：社保の最適化は可能か
- 青色申告65万円控除：e-Tax＋複式簿記の要件を満たしているか
- 青色事業専従者給与：家族に給与を支払って所得分散できるか
- 小規模企業共済：掛金は上限（月7万）まで活用しているか、増額の効果
- 経営セーフティ共済（倒産防止共済）：掛金の全額経費算入（月20万上限）
- 家事按分の最適化：自宅作業の場合の按分率（家賃・光熱費・通信費・車両費）
- 少額減価償却資産：30万円未満の資産の即時経費化（青色申告者のみ、年300万円上限）
- 消費税：インボイス制度への対応状況、免税事業者のままでよいか
- 予定納税・中間納付の資金計画

以下の形式で出力：
- 個人 vs 法人の税負担比較表
- 推奨する節税施策と年間効果額一覧
- 実行スケジュール（今すぐ・年内・来年度から）

- 年間売上：[金額]
- 年間経費：[金額と主な内訳]
- 事業所得（売上−経費）：[金額]
- 現在の事業形態：個人事業主 / 法人

- 家族構成：[事業に関わる家族の有無]
```

## 3. フリーランス・クリエイター専用 税務システム

> 元ネタ: #9 Grant Thornton Freelancer and Creator Tax System
> **いのさんに最も関連度が高い**

```
あなたはフリーランスやコンテンツクリエイターの税務に特化した税理士です。SNS運用・アフィリエイト・デジタルコンテンツ販売など、複数の収入源を持つクリエイターの税務を最適化してください。

構築する税務システム：

- 収入の分類と管理フレームワーク
  （アフィリエイト報酬 / デジタルコンテンツ販売 / 紹介手数料 / 広告収入 / コンサル / 著作権使用料）
  → 各収入の所得区分（事業所得 or 雑所得）の判定基準
- 経費の完全リスト（クリエイター特有）
  - 撮影機材・PC・スマホ（10万円超は減価償却、30万円未満は即時経費）
  - ソフトウェア・サブスク（Adobe, Canva, ChatGPT, 分析ツール等）
  - 通信費（スマホ・Wi-Fi・ドメイン・サーバー）
  - 取材費・旅費交通費（ホテル宿泊記事のための宿泊費等）
  - 書籍・セミナー・オンライン講座（研修費）
  - ワーキングスペース・カフェ（会議費・雑費）
  - 外注費（デザイン・編集・翻訳）
  - 広告宣伝費（Instagram広告・プロモーション）
  - 荷造運賃・消耗品費
- 家事按分の設定ガイド
  - 自宅の作業スペース比率（面積按分 or 時間按分）
  - 通信費（事業使用割合の合理的根拠の作り方）
  - 電気代（作業時間ベースの按分計算）
- 確定申告の年間スケジュール
  - 1月：前年の帳簿締め・決算整理
  - 2月16日〜3月15日：確定申告期間
  - 3月末：消費税申告期限（課税事業者の場合）
  - 6月：住民税通知 → 年間税額の確認
  - 7月・11月：予定納税（所得税）
  - 12月：年末の経費計上・ふるさと納税の調整
- 帳簿管理のベストプラクティス
  - 複式簿記（65万円控除の要件）
  - 領収書・レシートの保存ルール（7年間）
  - クラウド会計（freee / マネーフォワード / やよい）の選び方
- 消費税・インボイスの判断
  - 課税売上1,000万円以下なら免税事業者の選択肢
  - インボイス登録のメリット・デメリット
  - 2割特例（インボイス登録した免税事業者向け簡易計算）

以下の形式で出力：
- 収入分類テンプレート
- 経費チェックリスト（カテゴリ別）
- 年間税務カレンダー
- 家事按分の設定シート

【私の状況】
- 活動内容：[SNSプラットフォーム、コンテンツの種類]
- 収入源と年間金額：[各収入の内訳]
- 主な経費：[現在計上しているもの]
- 事業形態：個人事業主 / 副業（給与所得あり）
- 消費税：免税事業者 / 課税事業者 / インボイス登録済み
- 使用している会計ソフト：[あれば]
- 今困っていること：[具体的に]
```

## 4. 投資の税務最適化

> 元ネタ: #4 KPMG Investment Tax Strategist

```
あなたは投資税務の専門家で、個人投資家のポートフォリオにかかる税負担を最小化するアドバイザーです。日本の税制に基づき、口座の使い分けや損益通算を最適化してください。

最適化する項目：

- 口座の使い分け戦略
  - 特定口座（源泉徴収あり）：確定申告不要の利便性 vs 損益通算のための申告
  - 特定口座（源泉徴収なし）：年間20万円以下なら申告不要の活用
  - 一般口座：自分で損益計算が必要。どんな場合に使うべきか
  - NISA（つみたて投資枠・成長投資枠）：非課税枠の最大活用
  - iDeCo：掛金の全額所得控除＋運用益非課税のダブルメリット
- 損益通算の戦略
  - 上場株式等の譲渡損と配当の通算（申告分離課税を選択）
  - 特定口座間の損益通算（確定申告が必要）
  - 3年間の繰越控除：損失が出た年に確定申告しておく重要性
- 配当課税の最適選択
  - 総合課税 vs 申告分離課税 vs 申告不要：所得水準別の有利判定
  - 配当控除（総合課税選択時）の効果計算
  - 住民税の申告不要制度（2024年度以降の変更点に注意）
- 外国税額控除
  - 米国株・ETFの配当にかかる現地源泉税（10%）の二重課税排除
  - 外国税額控除の限度額計算と繰越（3年間）
- 金・プラチナ・銀の譲渡
  - 総合課税の譲渡所得として申告（50万円の特別控除）
  - 5年超保有なら長期譲渡所得（1/2課税）
- 暗号資産（仮想通貨）
  - 雑所得（総合課税）：最大55%（所得税45%+住民税10%）
  - 損益通算不可（他の所得と相殺できない）
  - 総平均法 or 移動平均法の選択

以下の形式で出力：
- 口座別・資産別の税率比較表
- 損益通算のフローチャート
- 今年実行すべき税務アクション一覧

【私のポートフォリオ】
- 保有口座：[特定口座 / 一般口座 / NISA / iDeCo の内訳]
- 保有資産と含み損益：[株式・投信・ETF・金等の概要]
- 配当収入：[年間概算]
- 今年の実現損益：[確定した利益・損失]
- 外国株式：[保有の有無と配当の有無]
- 暗号資産：[取引の有無]
```

## 5. 年末駆け込み節税チェックリスト

> 元ネタ: #13 RSM Year-End Tax Move Strategist

```
あなたは年末の税務対策に精通した税理士です。12月31日までに実行可能な節税アクションを、効果額の大きい順にリストアップしてください。

チェック項目：

- ふるさと納税の残額確認
  - 控除上限額の計算（所得・控除から逆算）
  - 12月末までに寄附＆決済完了が必要（ワンストップ特例 or 確定申告）
- 小規模企業共済の年払い
  - 12月中に年払い（最大84万円）で今年の所得控除に算入
  - 増額する場合は12月中に手続き
- 経営セーフティ共済の前納
  - 決算月の前月までに前納すれば今期の経費（最大240万円/年）
- iDeCoの年単位拠出
  - 12月分までの掛金引き落とし確認
  - 年払いに変更していた場合の確認
- 30万円未満の資産購入（少額減価償却）
  - PCやカメラなど、年内に購入・使用開始すれば今年の経費
  - 年間300万円の上限に注意
- 経費の前倒し計上
  - 年間契約のサブスク（1月〜の分）を12月に支払い → 短期前払費用の特例
  - 消耗品の年内購入
- 損失の確定（損益通算・繰越控除）
  - 含み損のある株式を年内に売却 → 利益と相殺
  - 損失を確定申告で繰り越すなら年内に売却完了が必要
- 医療費控除の集計
  - 年間10万円超（or 所得の5%）なら医療費控除
  - 12月中の通院・薬代も対象
- 生命保険料控除の確認
  - 新制度・旧制度の区分確認
  - 一般・介護医療・個人年金の3枠（最大12万円控除）を使い切っているか
- 配偶者・扶養控除の確認
  - 配偶者の年間所得が48万円以下（給与なら103万円以下）か確認
  - 扶養親族の年齢・所得要件の確認

以下の形式で出力：
- 期限付きアクションリスト（12月31日まで / 翌年3月15日まで）
- 各施策の推定節税額
- 優先度ランキング

【今年の状況】
- 今年の事業所得（見込み）：[金額]
- 投資の実現損益：[金額]
- 既に実施済みの控除・ふるさと納税：[内容]
- 大きな出費・ライフイベント：[あれば]
- 来年の所得見込み：[増減の方向性]
```

## 6. 税務調査対策・記録管理システム

> 元ネタ: #12 Deloitte Audit Defense Preparer

```
あなたは税務調査対応の専門家です。個人事業主が税務調査で指摘を受けないための記録管理システムを構築し、万が一の調査にも対応できる準備を整えてください。

準備する項目：

- 税務調査リスクの評価
  - 売上規模・業種・申告内容のどこが調査対象になりやすいか
  - アフィリエイト・クリエイター業種の調査ポイント
  - 経費率が高すぎる場合の目安（業種別の平均経費率との比較）
- 売上の記録体制
  - 全収入源のエビデンス（ASP管理画面のスクショ、振込明細、支払調書）
  - 売上の計上時期（発生主義：確定日 or 入金日の統一ルール）
  - 支払調書と申告額の突合確認
- 経費の証拠書類
  - 領収書・レシートの保存（7年間、電子保存OK）
  - クレジットカード明細だけでは不十分な経費（3万円超は領収書必須）
  - 事業との関連性を示すメモ（「〇〇の取材のため」等）
- 家事按分の根拠資料
  - 自宅の間取り図と作業スペースの面積計算
  - 通信費の按分根拠（スマホの使用ログ、事業用アプリの一覧等）
  - 光熱費の按分根拠（作業時間の記録）
- 交際費・取材費の管理
  - 飲食の場合：相手の名前・人数・目的を記録
  - 取材旅行：記事との紐付け、スケジュール記録
  - プライベートとの区分が曖昧なものの取り扱い
- 車両費・旅費の記録
  - 走行記録（日付・行先・距離・目的）
  - 事業用と私用の按分計算
- 調査時の対応マニュアル
  - 事前通知が来たらまず何をするか
  - 調査当日の心構えと対応のコツ
  - 税理士への依頼タイミング
  - 修正申告 vs 更正の違い

以下の形式で出力：
- 保存すべき書類チェックリスト（カテゴリ別）
- 月次・年次の記録ルーティン
- 調査対応フローチャート

【私の状況】
- 事業内容：[具体的に]
- 年間売上：[金額]
- 主な経費カテゴリと金額：[内訳]
- 家事按分の有無と現在の按分率：[あれば]
- 過去の税務調査経験：[有無]
```

```
- Year 1（今年度）の最優先アクション

  - 法人化の判断タイミング（売上の伸びに応じた再検討）

  - 売上変動が大きい場合の経費・控除の調整方法
  - 繰越控除・前払費用を使った年度間の所得調整

  - 結婚・出産 → 配偶者控除・扶養控除の発生

  - 所得税・住民税の税率改正リスク
  - 社会保険の適用拡大
- 年間レビューの仕組み
  - 四半期ごとの確認項目
  - 年末（11-12月）の最終調整チェック
  - 確定申告後（3月）の振り返りと翌年計画
```

## 8. 不動産投資の税務（日本版）
