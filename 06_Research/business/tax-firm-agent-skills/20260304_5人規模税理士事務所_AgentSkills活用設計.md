# 5人規模の税理士事務所 × AI Agent Skills 活用設計

> **作成日**: 2026-03-04
> **前提**: 社長（税理士）＋職員5人。税理士業務・会計業務・M&A・経営成長支援を提供
> **目的**: この規模で現実的に使えるAgent Skillsの設計

---

## 1. この規模の事務所の現実

### 典型的な体制（5人＋社長）

| 役割 | 人数 | 担当業務 |
|------|------|---------|
| 社長（税理士） | 1 | 税務判断の最終責任、M&A案件、大口顧問先、営業 |
| シニアスタッフ | 1-2 | 申告書作成、税務相談の一次対応、法人決算 |
| ジュニアスタッフ | 2-3 | 記帳代行、データ入力、年末調整、資料回収 |
| 事務 | 0-1 | 請求、来客対応、雑務 |

### 顧問先の規模感

| 指標 | 想定値 |
|------|--------|
| 顧問先数 | 80〜150社（法人＋個人事業主） |
| 月次顧問料 | 3〜10万円/社 |
| 年間売上 | 4,000〜8,000万円 |
| 1人あたり担当数 | 15〜30社 |

### 5人事務所のボトルネック（本質的な課題）

```
┌──────────────────────────────────────────────────┐
│                                                  │
│   社長の頭の中にしかない判断基準                    │
│   ↓                                              │
│   社長が全案件をレビューしないと出せない             │
│   ↓                                              │
│   社長がボトルネック → 売上の天井                    │
│   ↓                                              │
│   M&A・成長支援に時間を割けない                     │
│   ↓                                              │
│   高単価サービスが育たない → 記帳代行で疲弊         │
│                                                  │
└──────────────────────────────────────────────────┘
```

**Agent Skillsの本質的な価値 = 「社長の判断力の複製」**

## 2. 業務別のAgent活用マップ

### 全体像

```
収益構造（現状 → 目標）

  記帳・申告（70%） ─→ 50%に圧縮（Agentで効率化）
  税務相談  （20%） ─→ 25%に拡大（Agentで品質均一化）
  M&A・成長支援（10%）→ 25%に拡大（Agentで社長の時間を創出）
```

---

### A. 記帳・月次巡回（効率化 → 時間を生む）

**現状の問題**: 全体の工数の7割を食っている。ジュニアが時間を取られ、育たない。

| Agent Skill | やること | 効果 |
|------------|---------|------|
| `/monthly-check` | 月次試算表の異常値検知 | 前年同月比・勘定科目の異常をフラグ。人が見る前にAIが下見 |
| `/bank-reconcile` | 預金残高の照合チェック | 通帳と帳簿の差異を自動検出、原因の候補を提示 |
| `/receipt-classify` | 領収書・レシートの仕訳候補生成 | スキャンデータから勘定科目・摘要の候補を提示 |
| `/client-reminder` | 資料催促メール自動生成 | 未提出の顧問先に「〇月分の領収書がまだです」を自動ドラフト |

**効果の試算**:
- 月次チェック: 1社30分 → 10分（▲67%）
- 100社 × 20分削減 = **月33時間の創出**（≒ 職員0.2人分）

---

### B. 確定申告・決算（品質向上＋時間短縮）

**現状の問題**: 11月〜3月に集中。残業地獄。ミスも起きやすい。

| Agent Skill | やること | 効果 |
|------------|---------|------|
| `/tax-return-review` | 申告書の整合性チェック | 決算書と申告書の数値突合、控除の漏れ検知 |
| `/deduction-scan` | 所得控除の漏れチェック | 顧問先データから「使えるのに使ってない控除」を検出 |
| `/yearend-prep` | 年末調整の事前チェックリスト | 従業員別の必要書類リストを自動生成 |
| `/filing-status` | 申告進捗ダッシュボード | 全顧問先の申告ステータスを一覧化、遅れをアラート |

**効果の試算**:
- 申告書レビュー: 1件2時間 → 45分（▲63%）
- 繁忙期100件 × 75分削減 = **125時間の創出**
- 控除漏れ検知 → 顧問先あたり年間数万円の節税 → **顧問先満足度UP**

---

### C. 税務相談・節税提案（付加価値UP → 顧問料の根拠）

**現状の問題**: 社長かシニアしか対応できない。ジュニアが育つのに5年かかる。

| Agent Skill | やること | 効果 |
|------------|---------|------|
| `/tax-diagnostic` | 税務ヘルスチェック報告書 | 顧問先の財務データから節税余地を自動診断 |
| `/incorporation-sim` | 法人化シミュレーション | 個人事業主の顧問先に「法人化した場合」の比較表を生成 |
| `/optimization-report` | 節税提案レポート | 年1回、全顧問先に「あなたの節税余地」レポートを配布 |
| `/furusato-calc` | ふるさと納税上限計算 | 顧問先ごとの最適額を一括計算 |
| `/tax-qa` | 税務Q&Aアシスタント | ジュニアが顧問先から受けた質問の回答ドラフトを生成 |

**これが最も価値が高い理由**:

```
Before:
  顧問先「法人化した方がいいですか？」
  → ジュニア「確認して折り返します」
  → 社長に確認（社長が忙しくて2日後）
  → 社長が口頭で回答案を伝える
  → ジュニアが電話で回答
  → 3日経過。顧問先は「遅い」と感じている

After:
  顧問先「法人化した方がいいですか？」
  → ジュニアが /incorporation-sim を実行（5分）
  → 比較表の下書きが生成される
  → 社長が1分でレビュー・承認
  → ジュニアがその場で回答 or 翌日レポート送付
  → 顧問先「この事務所、提案力がすごい」
```

**効果**:
- 社長の判断待ち時間: 2日 → 10分
- ジュニアの対応品質: シニア級に引き上げ
- 顧問先の体験: 「聞いたらすぐ答えが来る事務所」

---

### D. M&A支援（高単価サービスの拡大）

**現状の問題**: 社長が1人でやっている。年に数件。もっとやりたいが時間がない。

| Agent Skill | やること | 効果 |
|------------|---------|------|
| `/valuation-draft` | 企業価値算定の下書き | 財務データから簡易DCF・類似会社比較法のドラフト |
| `/dd-checklist` | デューデリジェンスのチェックリスト | 対象企業の業種・規模に応じたDD項目を自動生成 |
| `/tax-dd` | 税務DDレポートのドラフト | 過去の申告書から税務リスクを洗い出し |
| `/deal-structure` | ストラクチャー比較 | 株式譲渡 vs 事業譲渡 vs 会社分割の税務比較表 |
| `/pmi-plan` | PMI（統合）の税務チェックリスト | M&A後の届出・申告・組織再編の期限管理 |

**効果**:
- 企業価値算定の下書き: 2日 → 3時間
- DDチェックリスト: 社長の頭の中 → 型化されて誰でも初動できる
- **社長の時間創出 → 年間M&A案件数: 3件 → 8件（+5件 × 報酬100-300万 = +500-1500万/年）**

---

### E. 経営成長支援（顧問料の上位プラン）

**現状の問題**: 「税金の計算屋」から脱却したいが、提供する武器がない。

| Agent Skill | やること | 効果 |
|------------|---------|------|
| `/kpi-dashboard` | 月次KPIレポート | 試算表から経営指標（粗利率・人件費率・損益分岐点等）を自動算出 |
| `/cash-forecast` | 資金繰り予測 | 過去データから3-6ヶ月の資金繰りを予測、危険月をアラート |
| `/benchmark` | 業界ベンチマーク比較 | TKC経営指標等と比較して「御社は同業他社と比べてここが弱い」 |
| `/growth-plan` | 成長シナリオ分析 | 「売上20%増」「新店舗出店」等のシナリオ別P/L・税負担シミュレーション |
| `/subsidy-search` | 補助金・助成金の候補検索 | 業種・規模・地域から使える補助金を提案 |

**これが事業モデルを変える理由**:

```
現状の顧問サービス:
  月3-5万 × 100社 = 月300-500万
  内容: 記帳＋申告＋質問対応
  顧問先の認識: 「税金の計算をしてくれる人」

Agentで拡張した顧問サービス:
  月5-10万 × 100社 = 月500-1000万
  内容: 記帳＋申告＋節税提案＋KPIレポート＋資金繰り＋成長支援
  顧問先の認識: 「経営の相談相手」
```

**顧問料の月額2-5万円アップ × 100社 = 月200-500万の増収**

## 3. 導入ロードマップ（現実的な順序）

### Phase 0: 準備（1ヶ月目）

- [ ] 事務所内の業務フローを棚卸し（何に何時間使っているか）
- [ ] 社長の「判断基準」をヒアリングして文書化（最重要）
- [ ] 会計ソフト（freee/マネフォ/弥生/TKC）のAPI連携可否を確認

### Phase 1: 内部効率化（2-3ヶ月目）

**まず社内で使う。顧問先には見せない。**

導入するSkill:
1. `/tax-qa` — ジュニアの質問対応を支援（社長の負荷軽減の即効薬）
2. `/deduction-scan` — 申告前の控除漏れチェック（品質向上）
3. `/client-reminder` — 資料催促の自動化（地味だが効果大）

期待効果:
- 社長への質問エスカレーション: ▲50%
- 資料催促の工数: ▲80%
- 控除漏れ: ▲90%

### Phase 2: 提案力強化（4-6ヶ月目）

**顧問先に見える形で価値を出す。**

導入するSkill:
4. `/tax-diagnostic` — 全顧問先に税務ヘルスチェックを配布
5. `/incorporation-sim` — 個人事業主への法人化提案
6. `/furusato-calc` — ふるさと納税の最適額通知

期待効果:
- 法人化提案 → 法人設立報酬（10-30万/件）＋法人顧問（月5-10万に増額）
- 「提案してくれる事務所」として紹介が増える
- ふるさと納税通知 → 手間ゼロで顧問先満足度UP

### Phase 3: 高付加価値サービス（7-12ヶ月目）

**単価を上げる。記帳代行屋から経営パートナーへ。**

導入するSkill:
7. `/kpi-dashboard` — 月次KPIレポートの自動配信
8. `/cash-forecast` — 資金繰り予測
9. `/growth-plan` — 成長シナリオ分析

期待効果:
- 上位顧問プラン（月10万〜）の新設
- 「税理士を変えたい」層からの新規獲得
- 顧問先の成長 → 顧問先の売上UP → 顧問料の自然増

### Phase 4: M&A強化（12ヶ月目〜）

導入するSkill:
10. `/valuation-draft` — 簡易企業価値算定
11. `/dd-checklist` — DDの型化
12. `/deal-structure` — ストラクチャー比較

期待効果:
- M&A案件の処理速度UP → 受任件数増
- ジュニアがDDの初動を担当可能に → 社長はクロージングに集中

## 5. 5人事務所だからこそ効く理由

| 大規模法人（50人+） | 5人事務所 |
|-------------------|----------|
| すでに部門別に専門家がいる | **1人が何役もやる → Agentの代替効果が大きい** |
| 社内に研修制度がある | **OJTだけ → Agentが教育ツールになる** |
| 判断基準がマニュアル化されている | **社長の頭の中 → Agent化の価値が最大** |
| 導入に稟議・承認が必要 | **社長が決めたら明日から使える** |
| IT部門が必要 | **クラウドツールで十分。専任不要** |

**小さい事務所ほど、1つのAgentの導入効果が全体に波及する。**

## 6. リスクと対策

| リスク | 対策 |
|--------|------|
| AIが間違った税務判断を出す | **全出力に税理士のレビューを必須にする**。AIは「下書き」の位置づけ |
| 職員が「仕事を奪われる」と抵抗 | 「雑務を減らして提案業務に集中できる」と説明。実際に経験する |
| 顧問先データの漏洩 | API送信データの匿名化、社内ポリシー策定、契約書への明記 |
| 税理士法52条（無資格者の税務相談） | AIは「ツール」であり税務判断は税理士が行う建付け。顧問先への直接回答はさせない |
| 導入したが使われない | Phase 1で「1つだけ」導入して成功体験を作る。全部一気にやらない |

## 7. 最初の一手（明日からできること）

**最も即効性があるのは `/tax-qa`（税務Q&Aアシスタント）**

```
実装イメージ（最小構成）:

1. 社長へのヒアリング（2-3時間）
   - 「よくある質問TOP20」を聞き出す
   - 各質問への回答パターンと判断基準を言語化

2. プロンプトとして整理
   - 事務所の方針、よく使う税法、判断基準をシステムプロンプトに
   - タックスアンサーのURLリストを参照データに

3. ジュニアが使う
   - 顧問先から質問 → まずAgentに入力 → ドラフト回答を取得
   - 社長に「この回答で合ってますか？」と確認（回答案があるから確認が速い）
   - 社長がOKなら送信

4. ナレッジが蓄積される
   - Q&Aの履歴が事務所のナレッジベースになる
   - 新人が入っても過去のQ&Aで学習できる
```

**初期投資: ほぼゼロ（Claude API月額数千円〜）**
**効果: 社長への質問エスカレーション50%減 → 社長の時間が月10-20時間生まれる**
