# 新社会人・若年層向けマイルカード コンテンツ企画リサーチ

> 調査日: 2026-03-04
> テーマ: 18〜29歳がマイルを貯め始めるためのクレジットカード選び

---

## 1. 競合コンテンツ分析

### 検索上位コンテンツの傾向

| プラットフォーム | 主な切り口 | フォーマット |
|---|---|---|
| ブログ/アフィ | 「マイルが貯まる最強カード○選」ランキング形式 | 比較表＋詳細レビュー |
| note | 「初心者でも10万マイル貯める裏ワザ」系 | ポイントサイト経由の陸マイラー手法 |
| YouTube | 「年会費の元は取れるか？」検証系 | 実体験＋数字シミュレーション |
| Instagram | カード券面デザイン＋還元率比較 | カルーセル（5〜10枚） |

### 競合の共通訴求ポイント
- 還元率の高さ（「1%以上は高還元」）
- 年会費無料 or 実質無料
- 入会キャンペーンのマイル数
- 「ポイントサイト経由で大量マイル」というテクニック系

### **情報ギャップ（競合に欠けているもの）**
1. **ライフステージ別の最適カード提案** → ほぼ全員が「おすすめ○選」で終わっている。「学生→新社会人→20代後半」の段階的カード戦略を語る人が極めて少ない
2. **「月○万円利用で、どこに行けるか」の具体変換** → 還元率の数字は出すが「それで何ができるか」まで落とし込んでいない
3. **20代限定カード（JAL CLUB EST / ANA JCB CARD FIRST）の直接比較** → 個別レビューはあるが、「ANA派 vs JAL派」の意思決定フレームワークを提供する記事が少ない
4. **年会費の「投資対効果」をライフスタイルで計算** → 数字だけでなく「旅行何回分か」で可視化する切り口が弱い

## 2. ターゲットの悩み・検索意図

### 新社会人がマイルカードを選ぶ際の主な迷い

| 悩みカテゴリ | 具体的な疑問 |
|---|---|
| **そもそも論** | マイルって本当にお得？ポイント還元のほうがいいのでは？ |
| **ANA vs JAL** | どっちを貯めるべき？途中で変えられる？ |
| **年会費の壁** | 新社会人の給料で年会費7,700円は高い。元取れる？ |
| **審査への不安** | 就職したばかりでも審査通る？年収はいくら必要？ |
| **見栄・体裁** | 社会人が持って恥ずかしくないカードは？ |
| **使い方がわからない** | マイルの貯め方・使い方が複雑そう |
| **比較の困難さ** | カードが多すぎて選べない |

### Google検索のサジェスト傾向
- 「新社会人 クレジットカード おすすめ」「初めて」「作り方」
- 「マイル 貯め方 初心者」「マイル クレジットカード 年会費無料」
- 「20代 マイルカード」「学生 マイル 貯め方」
- 「ANA JAL どっち」「マイル 還元率 比較」

### よくある誤解
1. **「マイルはよく飛行機に乗る人だけのもの」** → カード決済だけで十分貯まる
2. **「年会費無料カード＝最強」** → 年会費を払ってもROI的に得なケースが多い
3. **「ポイント還元率だけで決めればいい」** → ボーナスマイル・有効期限・特典を加味すると話が変わる
4. **「マイルは飛行機にしか使えない」** → ホテル・ツアー・ショッピングにも交換可能

## 4. SNSでバズっている切り口

### Z世代の旅行トレンド（2026年）
- **1位**: ご当地グルメ爆食い旅（31.9%）
- **2位**: レトロ喫茶・純喫茶巡り（28.5%）
- 旅行情報収集の**1位はInstagram**（知るきっかけ・検討どちらも）
- **一人旅が急増**: 過去6ヶ月に一人旅した20代は45%、今後予定61%
- 海外は**韓国**が定番、**タイ**が次のトレンド
- **温泉・サウナ**も20代に人気

### エンゲージメントが高い投稿パターン

#### リール（REELS）
| 要素 | 効果的なパターン |
|---|---|
| 尺 | 15〜30秒が最適 |
| 冒頭 | 最初1〜2秒で「衝撃の数字」or「意外な事実」 |
| フック例 | 「月5万の買い物で沖縄タダになるカード知ってる？」 |
| 構成 | 問題提起→解決策→行動喚起 |
| BGM | トレンドサウンド使用（↗マーク） |
| ターゲット視聴完了率 | 50%以上で拡散ブースト |

#### カルーセル（FEED）
| 要素 | 効果的なパターン |
|---|---|
| 枚数 | 7〜10枚（保存率が最も高い） |
| 1枚目 | 「20代限定！年会費0円でマイルが貯まるカード」等のキャッチ |
| 中間 | 比較表・チェックリスト形式（保存されやすい） |
| 最終枚 | 「保存して見返してね」CTA |
| 形式 | スワイプ型の教育コンテンツ |
| 保存される条件 | 「後から見返したい」と思わせる実用情報 |

### バズりやすいテーマ×フォーマット組合せ

1. **「知らないと損する系」×リール** → 「20代だけが作れるカード、知らないの？」
2. **「比較表」×カルーセル** → ANA vs JAL 完全比較（保存数狙い）
3. **「シミュレーション」×カルーセル** → 月○万円で○○に行ける変換表
4. **「失敗談・後悔系」×リール** → 「新社会人の自分に言いたい。最初のカード選び、間違えた」
5. **「タイムリミット系」×リール** → 「29歳までしか作れないカードがある」

## 5. 差別化ポイント

### 競合との差別化マトリクス

| 切り口 | 一般的なクレカ系アカウント | いのさんの強み |
|---|---|---|
| 情報の質 | カード情報の羅列 | **旅行×決済の最適化**という独自軸 |
| ターゲット | 全年齢・広範 | **ライフステージ別**の具体提案が可能 |
| 訴求 | 還元率・年会費 | **「この買い物で○○に行ける」**という体験変換 |
| 信頼性 | アフィサイトの匿名感 | 2.4万フォロワーの実績＋実体験ベース |
| 深さ | 表面的な比較 | **マイル→ホテル→旅程**まで一気通貫で語れる |

### 差別化できるコンテンツ戦略

#### A. 「ライフステージ別・マイルカード最適解マップ」（最大の差別化ポイント）

競合にほぼ存在しない切り口。以下の段階設計が可能:

```
【学生】JALカード navi（年会費無料・減額マイル）
    ↓ 卒業
【新社会人（22〜24歳）】ANA JCB CARD FIRST or JAL CLUB EST
    ↓ 年収UP・旅行スタイル確立
【20代後半（25〜29歳）】ゴールドカードへの切替判断
    ↓ 30歳
【30代】20代限定カードが使えなくなる → プレミアムカードへ移行
```

**なぜ差別化になるか**: 「今の1枚」ではなく「人生の5〜10年を見据えたカード戦略」を語れるのは、旅行×決済最適化をテーマにするいのさんならではの視点。

#### B. 「体験変換」型コンテンツ

一般的なクレカ系:「還元率1.0%で年間6,000マイル」→ 数字で終わる
いのさん:「月5万の決済で1年半後に沖縄ビーチ。ホテルはこう選ぶ」→ **旅行体験まで接続**

ホテル・旅程の知見があるからこそ、マイル獲得→特典航空券→ホテル→旅行プラン、という**フルファネルのストーリー**が作れる。

#### C. 「ANA派 vs JAL派 診断」インタラクティブコンテンツ

- ストーリーズのアンケート・クイズ機能で「あなたはANA派？JAL派？」診断
- 「よく行く旅行先」「利用空港」「好きなラウンジ」などで分岐
- 結果からカード推薦 → DM誘導 or note記事誘導
- **エンゲージメント＋リスト化＋収益化**を同時に実現

#### D. 「29歳リミット」の緊急性訴求

ANA JCB CARD FIRST、JAL CLUB ESTは**29歳（または20代）まで限定**。この「期限付きの特権」は強い訴求ポイント:
- 「29歳を過ぎたら二度と作れない」
- 「年会費無料で毎年3,000マイルが消える」
- FOMOマーケティングとして非常に効果的

## 6. コンテンツ企画案（優先度順）

### 企画1: カルーセル「20代限定！タダでマイルが貯まる2枚のカード」
- **形式**: カルーセル 8〜10枚
- **内容**: ANA JCB CARD FIRST vs JAL CLUB EST の完全比較
- **狙い**: 保存数（資産型コンテンツ）
- **CTA**: 「ANA派かJAL派か、ストーリーで教えて」
- **収益接続**: Amex紹介へのブリッジ（上位カードへの興味喚起）

### 企画2: リール「月5万の買い物で沖縄タダになるカード」
- **形式**: リール 20〜25秒
- **フック**: 「毎月5万円カードで払ってる？それ、1年半で沖縄往復タダになるよ」
- **構成**: 問題提起(3秒)→カード紹介(8秒)→シミュレーション(7秒)→CTA(5秒)
- **狙い**: 再生数・リーチ拡大
- **タイミング**: 3月下旬〜4月（新社会人シーズン）

### 企画3: カルーセル「マイルカードの教科書｜学生→新社会人→20代後半」
- **形式**: カルーセル 10枚
- **内容**: ライフステージ別の最適カード＋切替タイミング
- **差別化**: 競合にほぼない切り口。「今だけ」でなく「5年先」を語る
- **狙い**: 保存数＋フォロー（「この人の情報、長く使える」と思わせる）
- **収益接続**: note記事（詳細版）への誘導

### 企画4: ストーリーズ「ANA派？JAL派？診断」
- **形式**: ストーリーズ 5〜7枚（アンケート・クイズ機能活用）
- **内容**: 質問形式で最適カードを診断
- **狙い**: エンゲージメント率UP＋DM誘導
- **収益接続**: 診断結果に応じた個別カード推薦

### 企画5: note記事「新社会人のためのマイルカード完全ガイド」
- **形式**: 有料note（2,480〜2,980円）
- **内容**: 全カード比較＋シミュレーション＋ライフステージ別戦略＋旅行先提案
- **差別化**: 「カード選び→マイル獲得→旅行体験」のフルファネルガイド
- **販売時期**: 3月中旬〜4月（新社会人需要ピーク）
